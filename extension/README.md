# 随行 · 小红书发布助手（Chrome 扩展）

把你「随行」里生成的小红书笔记，**在你自己的浏览器里**一键填进小红书创作服务平台。

- ✅ 服务器**不接触**你的小红书账号：登录态始终是你浏览器自己的 cookie
- ✅ 选择器由服务端下发（`/xhs/agent/selectors`），小红书改版时**不用重新装扩展**
- ✅ 填好后**你点发布**——发布动作永远由账号所有人完成
- ⚠️ 目前只支持桌面 Chrome / Edge（MV3）

---

## 1. 安装（开发者模式）

1. Chrome 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库的 `extension/` 目录
4. 记下扩展 ID（后续如需固定 ID 可自行配置）

## 2. 配置

点扩展图标 → 填两项：

| 字段 | 值 |
|---|---|
| 服务地址 | 你的随行后端，含 `/api/v1`，例如 `http://localhost:8090/api/v1` |
| 访问令牌 | 登录随行网页后，F12 → Application → Local Storage → `trip_planner_token` |

> 令牌只用于「领任务 / 回写状态」。它不等价于小红书账号；扩展从不读取或上传小红书的 cookie。

## 3. 使用

1. 在随行里打开行程 → 生成小红书笔记 → 点「发布到小红书」
2. 前端提示「任务已下发」（`state = pending_agent`）
3. 扩展每分钟轮询一次；也可以在弹窗点「立即检查任务」
4. 扩展会打开 `creator.xiaohongshu.com/publish/publish`，自动：
   - 切到「上传图文」
   - 上传封面图（服务端鉴权取图 → 本机 File）
   - 填标题、正文 + 话题
   - 关掉「图片可以编辑啦」等浮层
5. **你在页面上确认内容，点「发布」**
6. 扩展监听到发布成功（跳到笔记管理页 / 出现「发布成功」）后回写 `published`

## 4. 已知边界

| 边界 | 说明 |
|---|---|
| 只支持桌面 Chrome/Edge | 移动端浏览器装不了扩展（这是方案 B 的固有代价） |
| 需要登录创作服务平台 | 扩展用你当前浏览器会话；没登录会被判 `login_required` |
| 不代点发布 | 半自动是有意为之：风控与责任都落在"人确认"这一步 |
| 任务有效期 30 分钟 | 过期自动作废（`XHS_AGENT_TASK_TTL_MINUTES`），避免旧任务误发 |
| 同一行程重复点发布 | 旧任务自动作废（`superseded`），只留最新一条 |

## 5. 自检（不发布）

1. 打开 `chrome://extensions/` → 本扩展 → 「Service worker」看日志
2. 弹窗点「立即检查任务」→ 若返回「暂无待发布任务」，说明令牌/地址通了
3. 在随行里点一次发布 → 观察是否自动打开发布页并填好（**不要点发布**）
4. 想放弃这次任务：关掉页面即可，任务过期自动作废

## 6. 目录

```
extension/
├── manifest.json   # MV3 权限：storage / alarms / tabs + 两个域名
├── background.js   # 轮询任务、代取图片（绕开页面 CORS）、回写结果
├── content.js      # 页面侧填表（选择器全部来自服务端）
├── popup.html/js   # 配置与手动触发
└── README.md
```

## 7. 安全说明

- 扩展**不申请** `cookies` 权限，读不到你的小红书登录 cookie；
- 它只是在你已登录的页面里**模拟你自己**填表、点按钮；
- 令牌存在 `chrome.storage.local`，仅用于你自己的后端；换机器/换账号请重新粘贴；
- 若后端是公网地址，请务必用 HTTPS。
