# 路径 C 商业化调研：差异化功能变现

> 调研日期：2026-09-25
> 状态：调研完成，方案待验证（不构成立即投入）
> 上游决策：opc-doc/outputs/09-dashboard-review/review-20260919.md（瓶颈 C 资产沉淀 + 顺延 SaaS）

## 一、路径 C 全景：两个子方向

| 子方向 | C1：to-C 付费 Pro（SaaS） | C2：to-B 白标 / API / 私有部署 |
|---|---|---|
| 客户 | 终端旅行者 | DMO/旅游局、旅行社、内容平台、文旅集团 |
| 产品形态 | 云端托管：免费层引流 + Pro 订阅 | 规划引擎打包：API / 白标 widget / docker 私有部署 |
| 客单价 | ¥68-128/年 | 月费 ¥2k-10k 或一次 ¥30k-150k |
| 冷启动依赖 | 流量 + 留存 | 销售 + 信任 + 案例 |
| 与现有资产 | 复用所有已落地功能（配额化） | 复用 docker-compose 部署包 + OpenAPI + 前端 |

## 二、市场证据（2026-09 调研）

1. **DMO 市场已验证且爆发**：Mindtrip 35+ 目的地合作（Brand USA / Visit California / San Diego / Boston / Savannah / Visit Orlando 等），模式为"AI 行程规划嵌入旅游局官网/WhatsApp"，明确无预订履约——纯规划层，与本项目定位同构。论据：70% DMO 观测到 AI 搜索带来的有机流量下滑，29% 旅行者因 AI 推荐改变目的地选择。
2. **白标有小团队先例**：Simplified.Travel 为 DMO/酒店/旅行社提供白标 itinerary builder + API 集成；Expedia White Label 面向大企业。
3. **to-C 定价锚点**：Wanderlog Pro $39.99-49.99/年（AI 付费墙，免费层 5 条 AI 消息）；Layla $9.99/月 / $49.99/年；Wonderplan/MonkeyTravel 纯免费（可持续性未验证）→ 独立规划层付费区间共识 $30-60/年，国内折算 ¥68-128/年。
4. **警示**：纯规划层 to-C 订阅至今无成功跑通的先例——所有验证商业模式的玩家都靠预订/数据；Wanderlog 付费墙只对订阅者生效（同行者仍免费版）是短板。

## 三、C1 方案（to-C Pro）

**免费层（引流）**：核心规划 + 修订 + 分享 + 投票 + 导出 + 3 次/月 AI 规划。
**Pro 层候选**：无限额度 / Plan B（已落地）/ 无限协作与受邀编辑 / 城市攻略数据包 / 无品牌导出。
**成本量级**：DeepSeek 一次完整规划约 ¥0.05-0.1；服务器 ¥50-100/月。免费层 3 次/月 × 2000 活跃 ≈ 6000 次 ≈ 数百元/月，成本可承受；Pro ¥88/年转化 2-3% 即可覆盖。
**死穴**：0 用户 → 无流量 → C1 必须挂在路径 A（文章/开源引流）之后，不能单独启动。

## 四、C2 方案（to-B）

**客户排序**：① 国内文旅局/文旅集团（数字文旅预算，AI 行程热点）② 定制游/旅行社 ③ 旅游内容平台/攻略站。
**交付形态**：私有部署（docker-compose 已 ready，数据不出域——文旅局强卖点）/ 白标前端组件 / API + OpenAPI 文档。
**定价**：SaaS API ¥2k-10k/月；私有部署 ¥30k-150k 一次 + 年维护 20%；定制按人天 ¥2k-5k。
**风险**：销售周期长（一人公司现金流）；定制化蔓延（红线：单一客户需求要么抽象成通用能力、要么走服务单独报价）；数据源外部 key 的运维责任；无成功案例的信任门槛。

## 五、裁决：验证优先（低成本的共同入口）

C1/C2 均**不立即投入**（0 用户 / 0 案例 / 0 销售资源）。共同验证入口：

1. 上线公开 demo（deploy/ 已 ready）+ 一页 landing（免费试用 + 企业版咨询入口）
2. 文章发布引流（路径 A），收集 50-100 真实用户，观察分享/投票/修订使用率（C1 信号）+ B 端线索（C2 信号）
3. 访谈 3-5 个目标 B 端：问"现在怎么解决行程规划、花多少钱"，验证 C2 真实预算

**判定线**：
| 信号 | 判定 | 动作 |
|---|---|---|
| demo 用户高比例用协作/主动问 Pro | C1 有戏 | 付费墙 A/B（免费 3 次/月 → 提示升级） |
| 有 B 端明确来问 / 愿签 POC | C2 有戏 | 做一个白标 POC，按通用化抽象收定制费 |
| 两者都冷 | C 维持备选 | 继续 A（资产沉淀），不碰重资产 |

**明确不做**：先做 SaaS 再找用户（最贵错误）；免费帮 B 端定制换案例（定制项目坟场红线）。

## 六、与路径 A/B 的关系

- A（技术资产变现）= 主线，C 的流量与信任来源
- B（产品 SaaS）= C1 的规模化形态，需 C1 验证后推进
- C = 备选，验证通过才升格；验证成本 ≈ 一个周末 + 文章发布的增量代价
