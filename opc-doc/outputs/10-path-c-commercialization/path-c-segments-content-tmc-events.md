# 路径 C 子方向调研：旅游内容平台 / 企业差旅与会展

> 调研日期：2026-09-25
> 承接：opc-doc/outputs/10-path-c-commercialization/path-c-research.md
> 用户点名调研画像：③ 旅游内容平台/攻略站、④ 企业差旅/会展

## 一、画像 ③ 旅游内容平台/攻略站

### 证据
- 马蜂窝 CEO 陈罡（2025.06）：「旅游攻略看似是内容，实则是解决问题的工具型产品」——头部平台已把攻略升级为工具型产品（AI 路书/AI 小蚂）。
- 去哪儿的「AI 旅行工具箱」+ 小红书笔记导入 = 种草 → 行程转化，验证国内刚需。
- 飞猪「问一问」8 角色多智能体，马蜂窝 DeepSeek + 垂直精调模型齐上——**头部全部自研，不是客户是竞品**。
- 可切的中间层：垂直攻略站、旅行自媒体/MCN、本地生活内容号——有流量、有内容、无自研 AI。
- **王牌武器**：`task-note-import`（笔记/种草文本 → 结构化站点候选）已落地，正是「把现有内容变成行程」的钩子。

### 判断
- 机会真实但**不作首选切点**：① 内容平台预算锚点=流量/广告变现，工具付费意愿弱；② 集成需贴主站，周期长；③ 客户分散、客单价低。
- note-import 的正确用法 = **B 端获客钩子**（展示「粘贴攻略变行程」能力），不单独卖。

## 二、画像 ④ 企业差旅（TMC）— 砍掉

### 证据
- 携程商旅/合思/同程商旅/汇联易甄选/Navan/SAP Concur：战场 = 预订供应链 + 费控合规 + 报销闭环（8 大 AI Agent、等保三级、ISO27001、ERP 集成、RaaS 按结果付费）。
- 护城河 = 机票酒店库存 + 财务合规 + 报销体系。

### 判断
- 一人公司无供应链与合规资质，轻资产撞重资产 **必死**。写进不做清单。
- 唯一可借鉴：合思「按结果付费（RaaS）」商业模式；TMC 的「智能行程规划」只是其众多 Agent 之一，印证纯规划引擎在差旅是「功能」而非「产品」。

## 三、画像 ④' 会展/会议参会者行程 — 升格为路径 C 最高潜力子方向

### 证据
- 会务 SaaS 红海且验证付费：7Event（8000+ 场，报名/签到/票务/议程/微网站）、映目（4000 万场，报名/签到/日程/嘉宾/展商）、发会科技（报名→签到→核销全流程）。
- **共同盲区：全是「主办方视角」管理（报名/签到/票务/议程管理），没有「参会者视角」的 AI 行程规划**。
- 发会科技自述未来方向：「AI 智能推荐（根据参会者兴趣匹配议程）」——已规划未做透。
- 行业痛点：大会 3-5 天、多分论坛并行，参会者要「选哪些议程、中间怎么走、住哪、周边、差补」，目前全靠人工/纸面。

### 为什么我们几乎零改造就能打
| 现有能力 | 会展场景价值 |
|---|---|
| 多 Agent 规划（景点/天气/酒店 → 议程/交通/住宿） | 参会者输入兴趣 → 个人参会行程 |
| **议程 = 确定性数据**（时间/地点/主题/并行场次） | 比 POI 更可控、质检有真值、**幻觉更少** |
| diff 对话式修订 | 现场改行程（"下午听完去展区"） |
| 分享/投票/受邀编辑 | 同公司参会人拼行程、约饭 |
| 预算/城市基准价 | 差补、住宿标准 |
| 异步任务 + T-A-O trace | 主办方可观测、可回溯（透明卖点） |

### 交付形态
- **卖给会务 SaaS**（映目/7Event/发会科技类）：白标模块/API 嵌入其议程系统，作为 AI 增值能力——它们的客户渠道 = 我们的渠道。
- **直接卖给主办方**：参会者口袋行程助手（公众号/小程序内嵌）。

### 风险
- 会务 SaaS 可能自研（尤其头部映目已有 AI Agent 布局）；需要 POC 证明「接入 3 天 vs 自研 3 月」。
- 会展是一锤子买卖（每场单独办）→ 做成 SaaS 复用度是关键（一场活动的系统下届复用率低）。

## 四、裁决与验证

- ③ 不作首选；note-import 当钩子。
- ④ TMC 砍掉。
- ④' 会展参会者行程 = 路径 C 最高潜力子方向。

### 低成本验证（2-4 周）
1. 访谈 2-3 家会务 SaaS（映目/7Event/发会科技类）：「你们的议程系统有没有主办方提过『给参会者生成个人行程』的需求？」
2. 若 1 家以上有兴趣 → POC：拿一个公开大会议程数据（确定性结构化），套现有规划引擎出一版「参会者个人行程」demo（含并行场次选择/交通/住宿周边/预算），给访谈对象看。
3. 判定线：
   - POC 被认可 / 有明确预算 → 做第一个白标 POC，按通用化抽象 + 服务费报价（不免费定制）
   - 无人响应 / 都说"我们打算自研" → 维持备选，回到主线 A

## 五、不做清单更新

- ❌ 企业差旅 TMC（供应链+费控+合规重资产，一人公司必死）
- ❌ 内容平台工具单独售卖（预算锚点在流量；只当获客钩子）
- ❌ 免费帮 B 端定制换案例（定制项目坟场红线）
