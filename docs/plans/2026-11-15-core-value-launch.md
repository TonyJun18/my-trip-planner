## 三、执行计划（4 周，每阶段 ≤5h）

### W1 · 上线（3 晚 / ~5h）
- [ ] 香港轻量 2C2G + 域名 A 记录 + HTTPS 证书（宝塔反代方案已调研，docker-compose 直接搬）。
- [ ] **全新空库初始化**，dev 测试数据（30 用户 / 6 self-test）**绝不带上去**。
- [ ] 生产安全最小项：固定 `JWT_SECRET`、收紧 `CORS_ORIGINS`、关 debug、不暴露 5432。
- [ ] **最小埋点 5 事件**：`page_view` / `register` / `plan_submitted` / `plan_completed` / `share_created`。
      - 新表 `analytics_events` + `POST /analytics/event` + 前端打点。
      - ⚠️ 不挂 `trip_events`（避免污染行程事件流）。
- [ ] 朋友内测 5 人（选取标准：**未来 4–8 周有真实出行计划**，含 ≥1 非技术用户）。

### W2 · 获客与访谈（2 晚 + 碎片）
- [ ] 修朋友筛出的 bug（预期集中：表单认知 / 修订入口 / 注册摩擦——真实用户 ≠ self-test）。
- [ ] 小红书 2–3 篇真实种草：「我用自己做的 AI 工具规划了杭州/成都 3 日游」。
      - 诚实基调（呼应「诚实预算 / 可修订 / 中立不卖货」立场），配真实截图。
      - ⚠️ 小红书站外链接会限流 → 引导「主页 / 私信」，不放外链。
- [ ] 3–5 人种子访谈（每人 10 分钟）：哪里卡住 / 哪里不信任 / 哪步想放弃 / 什么让你想回来。
