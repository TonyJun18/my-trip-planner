# task-link-import-zh-eval 评估记录（2026-10-22）

> 背景：2026-10-21 竞品分析——圆周旅迹（中文）靠「粘贴小红书/穷游/马蜂窝攻略链接 → 景点结构化」
> 在五工具横测拿第一，解析准确率 85%+。我们 link_import 已入 main 但只提取 og:title/description。
> 结论：**可行 → 落地最小版（马蜂窝/穷游/携程/去哪儿/大众点评深度抽取），小红书保持降级**。

## 一、可行性矩阵（零凭证、纯 std-lib HTML 解析）

| 平台 | 页面结构 | 反爬风险 | 判定 | 实现策略 |
|---|---|---|---|---|
| 马蜂窝 mafengwo.cn | 攻略正文 + `/poi/<id>.html` 景点链接（锚文本=景点名） | 低（公开攻略页） | ✅ 可行 | POI 链接锚文本 + 正文块文本 |
| 穷游 qyer.com | 攻略/游记正文，段落结构良好 | 低 | ✅ 可行 | 正文块文本（同策略） |
| 携程 you.ctrip.com | 景点页 `/sight/` 链接 + 正文 | 中（部分页面壳渲染） | ⚠️ 部分可行 | POI 链接 + 正文；失败走降级 |
| 去哪儿 qunar.com | 攻略/列表页，结构可用 | 中 | ⚠️ 部分可行 | 同携程 |
| 大众点评 dianping.com | 商户页偏 JS 渲染 | 高 | ⚠️ 有限 | 正文抽取，失败降级 |
| 小红书 xiaohongshu.com | 强反爬（返回壳页面/需登录/签名参数） | 高 | ❌ 不做深度抽取 | 保持 og:meta 链接收藏降级，不回退已可用能力 |

## 二、实现（backend/app/services/link_import.py）

1. `_DEEP_EXTRACT_PLATFORMS = {mafengwo, qyer, ctrip, qunar, dianping, generic}`
2. `_extract_deep_text(html)`：
   - 丢弃 `<script>/<style>`（防 JS 文本污染候选）；
   - 抽 `<a href="/poi/|/sight/|/attraction/|/scenery/|/destination/">锚文本</a>` → `📍 名称` 行（最高置信信号）；
   - 块标签（p/li/h1-6/br/div…）转行、剥离其余标签、HTML 反转义 → 正文按行保留结构；
   - 截断 6000 字符（`_DEEP_TEXT_MAX_CHARS`），总 feed 上限 8000（`_FEED_MAX_CHARS`）。
3. 深度文本与 title/description 一起喂给 `note_import.parse_note`——**敌意剥离、类型/价格/时长推断全部复用**（同一输入同一输出，零重复逻辑）。
4. 降级链不变：抓取失败/无 meta → `extracted=false` 链接收藏（200，静默）。

## 三、验证

- `backend/tests/test_link_import.py`：**23 例全绿**（原 18 + 新增 5）
  - 马蜂窝 POI 链接进候选（西湖/灵隐寺，价格 75 元解析正确）
  - script 内容不进候选
  - 穷游平台识别 + 深度抽取
  - 小红书不做深度抽取（body 链接不进候选，保持 og 路径）
  - 正文注入文本仍被敌意剥离（「系统提示词」不出现）
- 全量回归：436 → 441 测试全绿。

## 四、诚实边界

- 深度抽取是**结构与文本启发式**，非圆周旅迹级别的 85% 准确率（后者可能有更深的页面适配 + 抽取模型）；
- 平台改版会导致选择器失效 → 降级为链接收藏，不报错（可接受）；
- 未接入真实动态页面测试（零网络约束），真实页面效果需线上验证后再调规则；
- 小红书反爬场景明确不做，避免维护成本与合规风险。
