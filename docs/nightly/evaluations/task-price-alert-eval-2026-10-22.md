# task-price-alert-eval 评估记录（2026-10-22）

> 背景：Mindtrip Personal Travel Assistant（2026-09-30 官方稿）核心差异「knows the traveler + 主动带回」，
> beta 转化 3x。我们画像 + 行为记忆已具备「knows traveler」一半，缺「主动提醒」一半。
> 结论：**价格提醒数据源不可行 → 降级关单；降级替代「行程内事件通知」已落地**（P1-4）。

## 一、数据源矩阵（免费/零凭证路线）

| 数据源 | 能力 | 凭证/成本 | 判定 |
|---|---|---|---|
| Google Flights | 价格趋势 + 提醒 | 需 Google 生态登录、反爬强、无公开 API | ❌ 不可用 |
| 高德开放平台 | POI/天气/路径 | 无价格提醒类接口 | ❌ 无接口 |
| Amadeus Self-Service | 机票/酒店报价 | 免费额度有限、需注册与商业条款 | ⚠️ 付费/受限 |
| Kiwi/Tequila API | 机票搜索 | 需合作申请 | ❌ 门槛高 |
| 携程/飞猪 | 实时价 | 无公开 API、反爬 | ❌ 不可用 |
| 通用搜索抓价（Tavily） | 网页摘要 | 价格时效性差、无法结构化 | ⚠️ 不可靠 |

**结论**：零凭证路线下没有可靠的「价格变动监测」数据源；接入付费 API 与「规划层免费自托管」定位冲突。

## 二、降级方案（已落地）

原 todo 已预判：不可行则降级为「行程内事件主动通知」——修订/协作/打卡/跳过/顺延事件推送 owner 与同伴。
该能力已在 **task-trip-event-notify（P1-4）** 完整实现：
- `trip_events` 表 + `event_service`（append-only + WS 广播）
- 写路径全接入（revise/check/skip/delay/comment/vote）
- 双路径 API（owner / share / edit token）
- 前端事件流（30s 轮询 + 未读红点 + PWA Notification）

## 三、决定

- **关单**：价格提醒不实现（数据源不可行、与免费自托管定位冲突）。
- 如未来接入付费价格源（Amadeus/合作渠道），可复用现有事件流通道推送「价格变动」事件，无需改架构。

## 四、诚实边界

- 「主动带回」体验目前由事件流覆盖行程内变更；跨平台的机票/酒店价格监测仍是空白（明确不做）。
- 未来若做，需要：付费数据源合约 + 价格快照存储 + 定时比价任务 + 通知限流（防打扰）。
