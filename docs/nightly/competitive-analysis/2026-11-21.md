## 0. 一句话结论

**「确认单归集 + 行前提醒」从独立工具差异点变成巨头主战场**：Booking Holdings 投入 $1 亿推出 Vayo（直接读用户收件箱里的确认单，含其他平台的预订）；Everway 把整套 MCP 服务开源（20 个工具 + OAuth 2.1 远程协议，免费档也可连只读）；Expedia 用 Layla Creator Studio 把「AI 规划→创作者内容→跟订佣金」做成闭环。**而我们 11-20 夜刚落地的 free-cancel-deadline（3 天单窗口）与 Everway 的「3 天 + 24 小时双时点提醒」相比仍有密度差距；「行程缺口审计」（空白天/未覆盖的夜/缺返程）仍是确定性审计的真空洞。**

## 一、竞品清单（5 个）

**1. Booking Holdings — Vayo（private beta，$100M 投资）**
Booking Holdings 推出 AI 旅行助手 Vayo，计划投入 $100M；与 Layla/Mindtrip 的对话式规划不同，**Vayo 的核心差异化是读取用户收件箱里的旅行确认单**——包括在其他平台（Expedia/航司/民宿）订的预订，自动把已确认的行程拼成一个整体视图（observer.com，2026-11）。**信号：巨头直接复刻 Everway 的确认单归集场景，且用邮箱自动读取（而非转发）——数据主权争议更大，反过来证明「转发私有地址 / 粘贴文本」的隐私友好路线有价值。**

**2. Everway（everway.ai，11 月中旬 PH launch 后功能页深挖）**
上夜已记录四个差异点，本夜官网 + GitHub 深挖出新细节：
- **免费取消提醒是双时点**：「Get a reminder 3 days and 24 hours before your hotel's free-cancellation deadline」（features 页明示）——不是单次提醒，而是 3 天 + 24h 两次。
- **MCP 已开源**：官方 repo `everway-ai/everway-mcp-server`，20 个工具（get_trip/list_itinerary_items/add_itinerary_item/update_itinerary_item/set_item_people/invite_viewer/revoke_invite…），远程 MCP + OAuth 2.1 + streamable HTTP，支持 Cursor/Claude/ChatGPT/VS Code/Gemini CLI；**免费档也可连**（只读 + 指向升级，不静默失败）；AGENTS.md 定义了 5 个 skill（add-bookings-from-text / **trip-gap-audit** / daily-briefing / trip-budget-report / share-trip）。
- **trip-gap-audit 是独立能力**：「Find what's missing: empty days, uncovered nights, missing transfers, no return flight」——行程缺口审计被做成 MCP skill，我们确定性质检里没有对应项。
- **隐私边界**：只看到用户转发的邮箱，MCP 权限与用户一致（owner 可读写、guest 只读），OAuth 撤销即断。
- 免费档 1 个行程，Pro $49/年（launch $29）；LambdaBase 备注短板：无日历直连、需逐封手动转发。

**3. Google — AI Mode Canvas 全面化（shattered.io 复盘 + blog.google 官方）**
Google 把 AI Mode 里的 Canvas 从 2025-11 的 US 桌面 Labs 实验推广进主 AI Mode 流程：描述目的地/时间/类型 → 组装航班/酒店/逐日行程；可追问权衡（「离 brunch 近但离徒步远」）；AI Mode 历史可回来继续；另有 Flight Deals（200+ 国家、60+ 语言）与 agentic 预订（blog.google，2026-11）。Gemini 3.8 Flash 提供截图定位/结构化 day-by-day/实时票价工具调用。**信号：上夜 Ask Maps（地图内生成）之外，搜索侧「对话规划 + 实时预订」也已产品化——独立工具「再生成一份行程」的空间进一步收窄。**

**4. Expedia Group — Fall Product Release（travelweekly，2026-11-11）**
Layla 能力回流三大品牌：对话式 AI 可端到端规划并预订（机票/车/酒店/活动），复杂行程由 Layla AI 研究 + **真人 advisor 代订并在行中支持**；**Layla Creator Studio**（创作者用模板建行程 → 发布到社媒 → 粉丝直接跟订 → 创作者拿佣金）；Expedia 新增对话式 Activity Planner（可预订活动/餐厅/事件）；Hotels.com 上线 Property Expert（用酒店详情+住客评价回答问题）与 AI Compare。**信号：创作者经济进入旅行规划——「规划→内容→交易」闭环从 OTA 自营延伸到网红带货；我们 12 月的内容沉淀策略（16/17/18 文）需补这一波。**

**5. Mindtrip（mindtrip.ai，11-11 Kentucky 官宣 + observer 复盘）**
DMO 合作常态化：与肯塔基州旅游部合作（kentuckytourism.com 内嵌对话式 AI），Mindtrip for Business 已服务 VisitLEX/Brand USA/Bahamas/Costa Rica/Puerto Rico/California 等 10+ 目的地；observer 复盘称其「记忆偏好」（assistant knows the traveler not just the trip）是当前头部差异化，但「商务出差 vs 周末游需要不同推荐」暴露记忆画像粒度问题。**信号：DMO 白标是独立工具供给侧护城河路径（我们 task-dmo-white-label 11-02 已关单，维持判断不追）。**

**补充（快速确认，无新差距）：**
- **slicktrip Layla 复盘**：40%+ 用户无目的地开始规划（2023 年 12% → 现在 40%），「先帮我想去哪」是入口之王——我们 task-inspiration-mode（灵感入口 23 目的地知识库）方向正确，维持。
- **Wonderplan/Tripnotes 2026 现状**：Wonderplan 仍是「快速第一稿」定位（免费模板）；Tripnotes 主打协作偏好合成；两者均无新增可借鉴差异点（voyaige/monkeytravel/simular 检索摘要，2026-11）。

## 三、差距 → 行动项（全部先入 §2 候选池，手册 §5 维持规则）

**G1.【候选评估升级·backend】task-cancel-reminder-24h：免费取消提醒补 24 小时二次时点** — 证据：Everway features 页明示「reminder 3 days **and 24 hours** before your hotel's free-cancellation deadline」（双时点）；我们 11-20 夜刚落地的 free-cancel-deadline 是 `(today, today+3]` 单窗口确定性纯函数 + 台账倒计时，**无 24h 二次提醒**（todo §3: c35b4c3/663c6d6 在案）。评估最小版：提醒纯函数窗口改为双时点（3 天 + 24h，幂等无重复触发）或仅补 24h 第二时点；复用既有 trio 事件/通知链路。可行则最小版 + 测试；不可行记降级关单（维持 3 天单窗口）。→ 候选池 P2。

**G2.【候选评估·backend】task-trip-gap-audit-eval：行程缺口确定性审计** — 证据：Everway MCP skill「trip-gap-audit：Find what's missing — empty days, uncovered nights, missing transfers, no return flight」（everway-ai/everway-mcp-server AGENTS.md）；我们质检五门（time_gate/weather_gate/repeat_gate/dynamic_facts/geo_gate）覆盖时间/天气/重复/动态事实/地理一致性，**无「结构缺口」确定性审计**——空白天、未覆盖的夜（无酒店站）、缺返程交通（首末城不回）、段间无衔接都不是现有 gate 的输出（grep backend/app/services 无 trip gap 对应服务）。评估最小版：纯函数读 plan days/stops（零凭证、与 quality_report 同构）→ 输出缺口清单 warnings + 质检卡/质检报告透出；可行性高（数据全部本地结构）。→ 候选池 P2。

**G3.【候选评估升级·backend/docs】task-mcp-export-eval 证据升级：Everway MCP 开源收敛「生态演变」风险** — 11-20 G4 记录的风险「MCP 生态仍在演变」已被实测收敛：Everway 官方 repo 开源 20 工具 + OAuth 2.1 + streamable HTTP + 5 大客户端支持矩阵（Cursor/Claude/ChatGPT/VS Code/Gemini CLI），免费档可连只读、Pro 解锁写；**MCP 已是旅行工具的可选标准出口**。我们 chat_trip_tools 只读内核（get_my_trips/get_trip_overview + property_qa + export JSON/ICS）天然可薄壳映射（get_trips/list/get_trip_overview/property_qa/export）。评估不变（薄壳 + README 自托管说明），证据更新为本夜开源细节，优先级可上调。→ 候选池 P2。

**G4.【内容沉淀·docs】content-platform-takeover-3 素材升级：平台挤压第三波 + 创作者经济** — 证据：Booking Vayo（$100M、读收件箱）+ Google Canvas 全面化 + **Expedia Layla Creator Studio（创作者模板→社媒发布→粉丝跟订→佣金，travelweekly 11-11）** = 11-20 的 18 文《地图就是规划器？》素材大幅加厚：平台挤压从「地图/对话/OTA」扩到「创作者内容 + 收件箱数据」双新通道。建议：18 文（候选池 P2）正文扩一段「创作者经济与收件箱争夺」，或裂为 19 文《收件箱就是行程？》；接 15/16/17/18 文；代码引用逐条核验与仓库一致（email_import 批量归集/free-cancel-deadline/六通道/导出与立场声明）。→ 候选池 P2。

**G5.（复核备注·不进队列）确认单归集战场升温，零凭证路线再获印证** — Vayo 全量读收件箱 vs Everway 转发私有地址 vs 我们粘贴/批量文本：巨头入场证明场景真实，但「全自动读邮箱」的数据主权/合规成本高，Everway「转发」是隐私友好中间态；我们零凭证粘贴 + 批量（11-20 落地）与「绝不接 Gmail OAuth」边界（2026-10 email-import 立项原文）继续成立，维护不排期。免费档 1 行程（Everway）/Pangora 5 次/年（11-20 记录）再证 quota 软提示路线（11-08 落地）正确。

## 四、对我们「小而锋利规划层」定位的含义

1. **「行前整理」缝隙正在被巨头和融资产品同时填**：Vayo（$100M）+ Everway（创业公司）+ Expedia Creator Studio 全部押「确认单/已订行程的组织与提醒」。我们的对应物 email_import 批量 + free-cancel-deadline 已经在 11-20 落地——**方向被市场验证，速度要跟上密度（24h 二次提醒）与广度（缺口审计）**。
2. **MCP 是「输出自由」的下一站，且成本已被开源参考压低**：Everway 给出完整参考实现（协议/权限模型/skill 组织），我们 chat_trip_tools 内核白送大半；评估落地优先级应高于签证等重数据任务。
3. **创作者经济闭环不是我们的战场**：Creator Studio 需要交易佣金基础设施（资质/分成/合规），与我们「零凭证零佣金」边界直接冲突；但「生成后内容化」（story 晒图卡）方向正确——把创作者经济当作 18/19 文的叙事素材而非功能目标。
4. **质检/诚实标注继续是差异化锚点**：Everway 自己承认「extraction can be wrong… 必须对照原确认单核验」；Google/Layla 均无质检体系。我们四维质检 + basis 口径 + 质检报告（11-14 落地）+ 行中视图的组合仍然无竞品齐备——维持主线。
