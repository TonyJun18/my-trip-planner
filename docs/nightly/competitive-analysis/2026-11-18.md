## 一、竞品清单（4 + 1 补充）

**1. Wonderplan**（wonderplan.ai，表单式免登录）
免登录、60 秒出单目的地日计划，编辑/换/删自由，PDF 离线导出免费无墙；无对话式引擎、无航班/租车、多国支持弱，一次独立测试还发现编造餐厅与指错镇（Layla 官方横测 + Dream Trip + comparisonmath 多源一致）。**11-18 新确认：结构化饮食过滤器（Halal/Vegan/素食等）直接进表单**（comparisonmath）——这是被多数竞品漏掉、也被我们漏掉的结构化输入。

**2. Mindtrip**（mindtrip.ai，视觉+对话+预订）
免费的「最完整专业工具」：11M POI 库、地图第一视图、Start Anywhere（链接/照片/截图→可编辑行程）；2026 连推 Mindtrip Flights（5-06，Sabre Mosaic + PayPal 对话内机票成交）与 Mindtrip Stays（7 月）、9-30 Personal Travel Assistant（记忆画像 + 盯价 + 简报 + 打包清单）（MonkeyTravel 8 家横测 + highlights + layla 对比文）。两个公认短板：多城/复杂路线判断弱（「gorgeous output, occasionally thin routing」）、改一处整体重生成（Dream Trip）。

**3. Layla**（layla.ai，Expedia 收购后）
本夜最大动态是**收购后产品转向**：年初卖点 live pricing + PriceLock 盯价（$49/年，曾引 Skyscanner/Booking.com/GetYourGuide）→ 2026-07-31 被 Expedia 收购（另有 8-04 说法，两源不一致）→ 主页改卖「AI 规划 + 人类旅行专家代订套餐」（建议 €100/人/晚起），官网不再点名 PriceLock 与合作伙伴（MonkeyTravel 10-28 App 读数为 4.6★/214 评分；Layla 自称 5M+ 用户 vs 1.1M+ trips，营销口径打架）。其官方对比文也承认市场三分层：Plan-only / Partial booking / Booked with human——独立工具的生存位被自己写出来了。

**4. Tripnotes 2.0**（tripnotes-2.webflow.io，回归在线）
note→map 文本导入 + iOS Live Activities 锁屏行中（10-17 已跟踪）；本夜检索无新动态，维持既有认知。

**5.（补充）MonkeyTravel**（monkeytravel.app）
「live trip」行中今日视图原创者（Today 默认页 + 打卡/跳过/迟到顺延/换替代 + 免账号同伴操作 + 打包/分摊/feed），2026-11 对比文中仍是全市场最独特的行中增量；我们 10-14 已对标落地 live today + 打包清单 + 费用分摊三件套。本夜无新差距。

## 三、差距 → 行动项

**G1（补功能候选，frontend）task-dietary-filter-chips-eval：结构化饮食标签**
证据：Wonderplan 把 Halal/Vegan/素食做成表单级结构化过滤（comparisonmath，2026-11 检索）；我们 prompts.py L148-150 已支持「口味/菜系偏好」freeform 词→关键词转换（川菜/海鲜/素食），但 PlanWizard 无结构化饮食 chips，用户要自己打字。最小版：PlanWizard 增「饮食偏好」chips（素食/清真/海鲜忌口/无麸质等）→ 预填为口味偏好关键词，零后端大改（复用既有 preference 转换），i18n 键。→ 进 §2 候选池，P2。

**G2（内容沉淀，docs）content-acquisition-season-2：17 文《收购季第二波》证据已足**
证据（全部 2026-11-18 检索）：①Expedia×Layla 收购后产品两次转向（live pricing/PriceLock → 人类专家套餐、€100/人/晚门槛）——「收购收编能力」而非「收编品牌」的续集；②Layla 官方对比文自认市场三分层（Plan-only / Partial booking / Booked with human）——恰好是 16 文《生成之后》的宏观版；③营销口径打架（5M 用户 vs 1.1M+ trips vs 214 评分）——被收购工具的信任漂移。与 15 文（收购季第一波）衔接、接 16 文，§2 候选池既有 `content-acquisition-season-2` 升级证据密度。→ 维持 §2 候选池，注明证据已齐，队列腾位即晋升。

**G3（复核备注，不进队列）免费无门槛成为默认起点**
Wonderplan 无 signup、Mindtrip 免费、Layla 规划免费——免费+低摩擦是 2026 默认；我们 guest-trial（10-15 评估关闭：LLM 多轮成本敞口 + 无 IP 限流）结论与本夜证据不矛盾，维持关闭；若白天要重开，需先立「IP 限流 + 配额表」底座（评估记录里已有重启条件）。仅备注，不立项。

**G4（复核备注，不进队列）盯价叙事接棒**
Layla PriceLock 已从官网消失（收购后移除命名），盯价卖点由 iMean（跨站实时价格扫描）等接棒；我们 price-watch-mini-eval（零凭证台账提醒，11-15 立项）仍是唯一不破零凭证边界的路线，触发条件不变，维持候选池。
