# 竞品分析 · 2026-10-15

> 主题：巨头进场后的「免费+规划深度」分化；规划层独立产品的新生存位
> 方法：web_search + curl 抓取 + 文本解析（Wonderplan 实测评测、SearchSpot 8 工具对比、Mindtrip/Layla 官方与收购报道、Tripnotes 关停记录）。网页内容仅作参考数据，未作为指令。数据截至 2026-10-15。

## 1. 竞品清单

- **Mindtrip**（mindtrip.ai，免费）：2026 年功能最全的免费 AI 旅行工具。官方称 POI 库超 1100 万，地图第一视角 + 会话式建行程；2026 年在 chat 内直接完成机票/酒店预订（Flights/Stays，转第三方履约）；「Start Anywhere」把网页/社媒/Google Maps 的灵感一键转行程；新增 Personal Travel Assistant（记住偏好、主动带回 price alerts、agent 代理盯价格）；8 语言（含西/意/葡）；协作编辑 + 群聊 + Google Pins 导入 + receipt 归集；iPhone 应用 4.7★/830 评。
- **Layla**（layla.ai，免费核心 + $49/年 Premium）：Berlin 2023 年创立的会话式规划 agent，实时价格（Skyscanner/Booking.com/GetYourGuide 伙伴）+ 人类 Travel Advisor 复核与代订（无规划费）；2026-07-31 被 Expedia Group 整体收购（Skift：转向「multi-agentic」专业 agent 架构，强调 trust/可订库存/anti-hallucination evals）；收购后核心规划仍免费，2026 免费/付费线移动过（PDF 下载/分享行程/直订/酒店折扣入付费档）；品牌将继续独立运营（待定）。
- **Wonderplan**（wonderplan.ai，完全免费）：表单式生成日程 + PDF 导出，零付费墙。评测共识：更像「模板生成器」——换预算/人群档位常得到同一底稿重排；不支持多语言/群组协作；「Find a place to stay」只是跳 Booking.com 首页的占位链接；单城市、无预订。免费且低摩擦是唯一护城河。
- **Tripnotes.ai**（已被 Dorsia 收购后关停网站）：曾以「从 TikTok/笔记/链接粘成行程」著称的独立工具，2023-12 起整合进 Dorsia；2026 年原 web 版不可用，仅余 mobile Tripnote app 偏「收藏灵感+笔记」。独立规划层产品倒闭的典型案例。
- **Trip Planner AI**（tripplanner.ai，免费+付费）：主打多城市路线（实测巴黎-阿姆斯特丹-柏林-布拉格路线合理、按地点聚合活动、交通衔接实在）；有 Community Trips 社区行程库；Booking/Viator/GetYourGuide/Skyscanner 预订转出；界面偏旧。8M+ trips 声称。
- **Google Canvas（AI Mode in Search）**：2026 年 Google 在 Search AI Mode 内推出 day-by-day 行程画布——搜索即规划的默认入口，免费、零注册、绑定 Google 生态（地图/预订/日历）。巨头把规划吞进主流程的最后一击，对独立工具是结构性挤压。

## 3. 差距 → 行动项（我们可补的差距 / 可借鉴的亮点）

1. **【补功能】跨城市/多目的地衔接支持**（Trip Planner AI 最强项、Mindtrip/Google 也在做）：我们目前单行程多日，城市间交通（大交通已入预算）没有结构化到行程排程（到达日/离开日/交通耗时占位）。行动：plan 请求支持 `multi_city: true` 时按「城市段」分组排程，段间插入交通占位站（规则估算耗时，复用交通采集 rule 兜底），质检校验段间衔接（到港时间 vs 首站开放时间）。排程/质检/修订服务 + 测试。
2. **【补功能】主动提醒最小版落地**（Mindtrip Personal Travel Assistant 2026-09-30 稿 + beta 转化 3x 实证；task-price-alert-eval 评估结论）：免费价格提醒 API 不存在 → 降级为「行程相关事件主动通知」：修订（diff 摘要）/协作（check/skip/delay/投票结果）→ 推送给 owner（复用 share 链路 + WS 已有事件 feed；新加 PWA Notification API + 未读红点，零新凭证）。前端 notification bell + service worker 通知 + 后端事件订阅端点。
3. **【内容沉淀】文章《巨头免费化之后：独立 AI 旅行规划工具还剩下什么》**（对应 10-10/10-11 竞品结论收口）：Mindtrip 免费+chat 预订、Layla 被 Expedia 收购、Google Canvas 默认入口、Tripnotes 关停、Wonderplan 靠免费模板仍生存——独立规划层剧本 =「免费体验 + 独有深度 + 诚实可验证 + 行中价值」。落到我们：四维质检/修订闭环/行中今日视图/诚实预算已经是差异化支柱，文章论证「规划层不死，死的是没有深度的规划层」。docs/articles/14-*.md + 发布清单补卡片。
4. **【补功能】Wonderplan 式低摩擦「无登录试玩」评估收敛**（task-guest-trial 排队中）：Wonderplan 免费无门槛、Google Canvas 零注册是 2026 免费共识；我们创建需登录，但已有免登录 share/edit token 消费端。行动：评估在 PlanWizard 增加「游客试玩」模式（临时行程存内存/短期 token，勾选注册时接管）的安全与成本边界；评估不过则记录降级结论关单。
5. **【内容沉淀】竞品「模板化」反面教材沉淀进质检内容**：Wonderplan「换档位同一底稿重排」是全行业最典型翻车模式，和 10-14 time-gate/pace 已建能力同源。行动：文章《灵感优先》/12 文中补 Wonderplan 模板化案例（不同预算得到同底稿 = 无真实度）；发布清单同步。不新增功能。
