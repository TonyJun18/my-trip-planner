## 3. 「差距 → 行动项」

1. **【补功能 · 中优先】Wanderlog 免费协作被打脸 → 我们的「群组投票/评论」值得补** — Wanderlog 免费层实时协作是最大卖点、MonkeyTravel 群组投票、Mindtrip co-edit 都在卷多人出行；我们仅做了只读分享（09-21）。→ **新增 `task-trip-collab-vote`**：在分享链路之上加轻量投票/评论（最小版：行程页评论 + 对每日站点 👍/👎 投票，仅需前端 + 简单接口，无复杂协同编辑）。记入 backlog，待 `task-trip-share` 合并稳定后评估。
2. **【补功能 · 低优先】迭代精修是免费差异化武器（iMean 启示）** — iMean AI 把「conversational refinement（反复微调）」做成卖点但免费仅 2 条消息；我们的「让 AI 调整行程」已经是 diff+原子应用的真修订，是所有竞品里唯一有回滚保障的。→ **不新增任务**，把修订能力写进 README 卖点与发布清单（并入 `content-diff-positioning` 执行范围），并考虑在首页露出修订演示入口。
3. **【内容沉淀 · 中优先】「预订闭环 vs 免费规划」市场分层文章** — 2026 行业最大变化是 Mindtrip agentic 订票 + Expedia 收购 Layla：资本把 AI 旅行卷向「可预订」。独立工具（含我们）的机会在**免费、透明、可修订的规划层**，把「先规划后预订」的分层讲清楚。→ **新增 `content-planning-vs-booking`**：写一篇《AI 旅行规划正在变成预订漏斗——独立工具的机会在「规划层」》（发布就绪草稿，docs/articles/06-planning-vs-booking.md）。
4. **【补功能 · 低优先】Wanderlog 式「手动修订清单」交互** — Wanderlog 的杀手锏是**手动自由改 + 地图联动**（AI 只是辅助）；我们修订靠对话一次一大改，缺「行程清单 → 单击编辑单日单点」的细粒度手动入口。→ **新增 `task-manual-edit`**：行程详情页站点卡片支持行内编辑（改标题/时间/顺序拖拽），AI 修订与手动编辑并存。记入 backlog（排在 `task-roadtrip-mode` 之后）。
5. **【内容沉淀 · 低优先】多语言/入境游窗口（同程 9 语 / Layla 16 语 / iPlan 8 语）** — 入境游是今年被反复验证的方向，但我们 i18n 任务（main 上未列入，09-22 分支有 task-i18n-base）尚未开始。→ 维持 09-22 结论：i18n 优先级让位于核心体验（roadtrip/collab），并入既有任务范围，不新增。

## 4. 结论（一句话）

2026 年 AI 旅行赛道已被资本推向「**可预订**」（Mindtrip 首创 agentic 机票、Layla 并入 Expedia），免费独立工具的生存空间在**规划层体验**——而这正是我们最强的领域（透明质检、可修订不回滚、真实数据）；下一阶段最值得补的是**协作投票**（多人出行）与**手动细粒度编辑**（Wanderlog 式），两者都是纯前端 + 轻接口、不依赖付费 API。
