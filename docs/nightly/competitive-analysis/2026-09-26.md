## 一、竞品清单（本夜聚焦 6 款，全部海外）

1. **AiGo**（theaigo.co，2026 活跃新玩家）—— 多智能体（Claude Sonnet 对话 + Gemini Flash 生成），<30 秒出全行程，覆盖 195+ 国家、10 种原生语言；**实时协作**（邀请朋友同编、live presence 在线指示器）、**多币种预算跟踪与分摊**、**PWA 离线访问**、**免登录 guest 模式**、26+ 预订合作伙伴，支持语音输入与**截图转行程（screenshot-to-itinerary）**。短板：绑定 26+ 预订伙伴的成交链路；协作实时度依赖其自有账号体系；3D 地图偏营销展示。
2. **iPlan.ai**（iplan.ai）—— 极致极速（30 秒内生成完整 day-by-day 草稿）与「给用户一个可反应的起点」哲学：五字段表单、无对话、无社交。三档节奏（relaxed/moderate/packed）产生**真正不同**的行程；**地理聚类**（同区域景点合理分组）获好评；免费额度慷慨（约 8 次/月）。短板：**预算估算粗糙（评测称偏差 20-30%，基于 pre-2023 数据）**；>14 天行程质量明显下降；免费版不能单日重生成；多城市/复杂逻辑弱。
3. **Wandercrafted**（wandercrafted.app）—— 主打**具体度**：命名餐厅（含价位档/菜系/氛围描述），餐厅与活动直接链 Google Maps，可真正预订/导航；免费版即可用 3 天行程，Pro $49.99/年解锁 28 天长行程、天气与预算估算、协作编辑；多城（免费 5 城）；iOS 全功能 App；导出 PDF/.ics/email/clipboard。短板：预算/天气等高级功能在付费墙后；规模小于 Wonderplan（98.4K vs 更大月访问）；协作编辑仅 Pro。
4. **Wonderplan**（承接 09-21/09-24/09-25）—— 免费/低付费（$9.99/月或 $99/年，免费 1-3 行程/月）。表单式，30-45 秒生成；**预算估计基于一般目的地数据而非实时价格**；对接天气按天气调度活动。短板：无协作、无预订、仅英文、输出「泛化建议」（如「高档意餐」而非具体餐厅——被 Wandercrafted 直接点名）。
5. **Trip Planner AI**（tripplanner.ai，承接 09-25）—— 自驾 AI 路书主打，经停/充电/风景路线优化；本夜不复述。
6. **Mindtrip**（承接）—— agentic 航班/酒店预订 + 协作聊天 + 灵感社区 + 收据整理；本夜不复述（预订层信号 09-24 已记）。

> 注：Tripnotes.ai（ChatGPT 版行程规划、45 天百万用户）2024-01 被收购后**已停运**——「粘贴笔记 → 行程」范式空缺，09-25 已据此落地 task-note-import（main 已并入）。

## 三、我们可补的差距 / 可借鉴的亮点（本夜 5 条）

### 差距 → 行动项

1. **【补功能】酒店价格真实度——「估算」必须透明化（iPlan.ai 翻车现场直接背书）**
   现状：todo 已有 `task-hotel-budget`（POI 类目 + 城市基准价估算模型），但未落地；竞品整体水平也低——iPlan.ai 预算估算被评测点名「偏差 20-30%、基于 pre-2023 旧数据」，Wonderplan 用一般目的地数据。**这意味着：价格估算不是差异化护城河，但「估算的透明度 + 可修正」可以是**——我们的城市基准价模型若能标注数据口径（基准年/来源/置信区间），并在修订时联动重算，就是规划层对「预订层实时价」的诚实替代。
   → 行动项（承接）：`task-hotel-budget` 落地时增加「估算口径标注」（source + 基准说明 + 置信度），reports 预算视图展示「估算 vs 实际可验证」。优先级高（已排队）。

2. **【补功能】预算分摊/多币种（AiGo 多币种+分摊是海外协作标配）**
   AiGo 在协作之外把「预算跟踪 + 多币种 + 分摊」做成了卖点；Wanderlog 也有预算协作。我们的行程分享/协作（WIP）目前没有预算层。多人出行时「这趟每人多少钱」是刚需，与 share 链路天然衔接。
   → 行动项：`task-budget-split`：行程级预算视图支持「人均分摊」（按成员/按天/按类别），行程元数据携带币种（当前人民币单币），预算项按成员标记。验收：分享页可看人均预算 + 测试覆盖。中优先级，排在 task-share-token-lifecycle 之后。

3. **【补功能】截图导入行程（AiGo screenshot-to-itinerary 是笔记导入的姊妹范式）**
   09-25 已落地文本笔记导入（task-note-import）；AiGo 把「截图转行程」做成独立卖点。去哪儿已验证小红书图片/笔记导入价值，**图片 OCR → 结构化站点候选**与文本导入共享管线。
   → 行动项：`task-screenshot-import`：行程创建页支持上传攻略截图 → OCR 提取站点候选（复用 task-note-import 的结构化提取与恶意注入处理管线）→ 勾选并入行程。验收：截图可生成站点候选 + 敌意输入仍按数据对待 + 测试覆盖。中-高优先级（国内小红书生态强相关）。

4. **【内容沉淀】《预算是 AI 行程工具最不诚实的部分》——估算透明度的规划层哲学**
   iPlan.ai 的 20-30% 偏差、Wonderplan 的一般目的地数据、Wandercrafted 把预算放付费墙——竞品集体在预算上「糊弄」。这正好是规划层差异化文章的好素材：预订层有实时价但绑架交易，规划层应提供**标注口径的诚实估算 + 可修订联动**。与 07/08 文构成「价格维度」姊妹篇。
   → 行动项：`content-budget-transparency`：写一篇发布就绪文章（docs/articles/09-…），以 iPlan.ai/Wonderplan/Wandercrafted 预算短板为引，讲「估算透明 + 修订联动」哲学，发布清单补卡片。低-中优先级。

5. **【内容沉淀/轻量功能】PWA 离线——行程在路上的可用性（AiGo 已验证，TripIt/Wanderlog 也有）**
   旅行场景弱网/无网是常态；AiGo 把 PWA 离线做成卖点。我们的行程是结构化 JSON，天然可离线缓存；前端 Service Worker + 行程详情页离线展示成本可控。
   → 行动项：`task-pwa-offline`（轻量）：前端加 Service Worker，缓存行程详情/api 响应，弱网时展示缓存行程 + 「离线模式」标识。验收：build 通过 + SW 注册 + 行程详情可离线打开。低优先级（排在核心补功能之后）。

### 亮点借鉴（不建任务，记录在案）

- **iPlan.ai 的地理聚类**：同区域景点合理分组的工程思路值得抄进规划器 prompt/后处理——「不打折的修」在假期质量上直接可见。可与 map-drag-edit 一起评估。
- **iPlan.ai 三档节奏产出真不同行程**：我们 plan_b 已落地，可借鉴「节奏差」作为主案/备案差异主轴之一。
- **AiGo guest 模式 + 30 秒生成**：验证「低摩擦启动」——我们的免登录 token 即用已对齐；生成速度非我们主打（质检优先），不追。
- **Wandercrafted 具体度**：命名餐厅+价位档直接链地图——我们 POI 体系若接入地图/点评数据可参考；当前不建任务（无外部 API 预算）。
