## 1. 竞品清单

- **Wonderplan**（wonderplan.ai，完全免费）：aitravel.tools 2026-04 实测首次正面拆穿——**不是对话式 AI，是模板生成器**：无聊天、无 prompt 框；可删除/重排卡片，但「添加新地点/替换推荐」失效、「View Full Itinerary」有时点不动；给带孩子的家庭推荐 ruin bar。Tracxn 显示马来西亚、unfunded。免费模板库 + PDF 导出仍是其全部护城河。
- **Mindtrip**（mindtrip.ai，免费+预订）：2026-09-30 Personal Travel Assistant 官方稿细节——「knows the traveler, not just the trip」：跨旅程记忆偏好、对话结束后 AI agents 继续监测（watch→surface updates）、预订与行程归集一体；09-10 与 South Dakota 旅游局合作（目的地 B 端输出）。免费+chat 内预订仍是全市场最全票。
- **Layla**（layla.ai，核心免费 + premium $49/年）：Expedia 2026-07-31 收购官宣后第三方实测（endlesstravelplans）——Trustpilot 仅 4.0/86 评、App Store 160 评，**「review base warmer but far thinner than marketing」**；收购后推荐中立性存疑（货架偏向 Expedia 生态）。16 语言声称。
- **Trip Planner AI**（tripplanner.ai，免费+转出变现）：multi-city 优化/transfer/过夜仍是最强项（10 天欧洲示例）；Community Trips + pre-built 模板出发；延续上夜无大变化。
- **Tripnotes 2.0**（tripnotes-2.webflow.io，回归在线）：本夜 web_search 确认站点仍在线（「Plan your next trip in seconds」）；iweaver 指产品重心转向 Tripnote 移动 app（手机端笔记管理）。note→map 范式与 10-17 记录一致，无新变化。
- **MonkeyTravel**（monkeytravel.app，免费，★本夜重点）：2026 群组页新实证——**4 级投票（Love / Flexible / Concerns / No）+ 实时 consensus 与参与率 + 角色权限（Owner / Editor / Voter / Viewer）**；「no account」邀请链接、免费 8 协作；行中三件套（今日视图/顺延/跳过/换替代 + 打包清单 + 费用分摊 + 变更 feed）；180+ 目的地、EN/ES/IT/PT。自家对比表承认无实时价格、无预订集成。
- **圆周旅迹**（中文，★本夜新增）：新浪 2026-07 五工具横测第一名——**粘贴小红书/穷游/Mafengwo 攻略链接 → 自动解析景点（名称/位置/建议时长/开放信息）→ 按地理+时间排行程**，解析准确率 85%+、完全免费无限次、不做预订（「规划与预订分开反而更干净」）。专注「攻略转行程」单场景做到极致。
- **中文巨头**（★本夜新增）：2026-10-14 ZAKER 实测——豆包一句话出机票酒店打包方案；千问×飞猪（1-15 接入）、元宝×同程（9-20 AI 旅行规划，攻略卡片直跳同程小程序）、飞猪帮帮履约（退改/升房/值机/填入境卡/开票）、千问 Go 替用户打电话（10-13）；同程程心 AI+DeepSeek（3-7 AI+实时预订）、携程 TripGenie 辅助订单同比 +400%、AI 规划用户转化 2x、9 月万事达对话内支付。ZentrumHub 基于 150 万真实预订测算：**AI 代理目前仅占酒店预订 3-5%**（2027 底 5-8%）；但 **65%+ 用户规划第一选择已是内容平台与 AI 工具**而非携程。马蜂窝 2026 AI+旅游趋势报告：AI 助手上线至 2025 年底生成 131.5 万份深度攻略、覆盖 55 国 416 城、省 471 万小时；Top10 提问关键词「便宜/小众/不踩雷/行程安排/人少/亲子/躺平/性价比/一天怎么玩/值不值得」；80% 用户预算 ≤6000 元（49% ≤3000 元）；3-5 天主流、6 天+ 占 40%；境内 77%。新浪横测三件 AI 做不好的事：**体力/天气预判**（华山估算 2h vs 实际 7h）、**个人偏好精准匹配**、**突发情况应对**；另证 ChatGPT 排昆明-大理 350km 进半天、周一闭馆博物馆照排；Wanderlog 中文数据覆盖率 <20%；马蜂窝完整行程需年费 198 元；携程 30 秒出结果但模板化、攻略链接解析弱、无协作。

## 3. 差距 → 行动项（我们可补的差距 / 可借鉴的亮点）

1. **【评估候选】协作民主化细粒度**（MonkeyTravel 4 级投票 + 参与率 + 角色权限 vs 我们二值 up/down + vote 混在 share token 里）。仓库核验：collab_service.StopVote 只有 value 二值、consensus=「响应数 ≥ ceil(规模/2) 且 up>down」，无参与率透出；share/edit 双 token 无 vote-only 档。「Love/Flexible/Concerns/No」四档 + 参与率的借鉴点：不响应成员 ≠ 反对，弹性档让共识更有信息量；vote-only 角色与「主人/协作者/投票人/观众」分级降低免登录同伴的操作半径。行动：先评估四档扩展与 vote-only 档的成本边界（schema 演进 + ShareView 交互），可行则最小版二选一（四档投票 或 vote-only 参数），否则记录降级。排在后端改动窗口。
   → 行动项 slug：**task-collab-democracy-eval**
2. **【补功能·轻量】体力负荷提示**（新浪横测点名「AI 做不好体力/天气预判」，华山 2h vs 实际 7h 为反例；Wonderplan 给家庭推夜店为同质翻车）。我们 time_validation 已有 OPEN_HOURS_BY_TYPE 类目基准，自然延伸：EXERTION_BY_TYPE 体力系数表（登山/徒步/暴走/常规类目）→ 单日体力负荷累计 + 阈值 warning（如含高强度站点提示「实际耗时可能显著上浮」）→ 复用质检 warning + timegate-card 前端透出通道；天气实时数据零凭证做不了，明确不做。这把我们「时间真实度」扩展为「时间+体力真实度」，是 12 文（翻车实录）论证的工程落地。
   → 行动项 slug：**task-exertion-check**
3. **【素材沉淀】中文市场证据包**（三大新信号供排队文章取用）：①圆周旅迹 85% 解析率 = 我们四通道导入/攻略链接增强的场景验证（供 11 文入口之争 + 行动项 4）；②巨头入口之争（豆包/千问×飞猪/元宝×同程/程心/携程 TripGenie +400%、AI 代理仅占预订 3-5% 但 65% 用户第一选择已是 AI 工具）= 14 文「规划层被吞」最新量数；③马蜂窝报告（131.5 万份攻略/关键词 Top10/预算 ≤6000 元占 80%）+ 新浪横测信任数据 = 13 文信任缺口与预算画像素材。行动：产出 docs/nightly/research/zh-market-2026-10-21.md 证据清单（每条例出处+可用文章位置），不写全文（12/13/14 文由对应 content-* 任务消化）。
   → 行动项 slug：**content-zh-market-evidence**
4. **【评估候选】中文攻略链接深度抽取**（圆周旅迹核心能力 = 粘贴小红书/穷游/马蜂窝链接 → 景点名/位置/建议时长/开放信息结构化；我们 link_import 已入 main 但只提取 og:title/description）。行动：评估三平台可行性矩阵（小红书反爬大概率挡 / 马蜂窝结构良好 / 穷游页结构可解析；纯 HTML std-lib 解析、零凭证、复用 note_import 敌意剥离 _INJECTION_RE 与 NoteStopCandidate），可行则最小版实现马蜂窝/穷游解析 + 测试覆盖，小红书降级为现有链接收藏不回退。与 task-email-import 的「零凭证最小版」哲学同构。
   → 行动项 slug：**task-link-import-zh-eval**
