## 3. 「差距 → 行动项」（追加进 todo）

1. **【补功能 · 高优先】主动提问/需求挖掘前置** — 马蜂窝 AI 路书「主动提问」机制是显著差异化：用户在表单之外没想到的细节（出行人群、节奏偏好、避峰、备选方案）通过 2-3 轮追问补齐，行程质量与个性化观感都更强。→ **新增 `task-active-questions`**：规划表单提交前置 1-3 个动态追问（人群/节奏/避峰/备选），答案并入规划上下文（验收：后端追加 questions 字段 + 前端交互 + 测试覆盖）。
2. **【补功能 · 中优先】历史对话记忆/用户画像** — 同程「记忆关联性」、飞猪「微细分记忆」、Layla「记住你是谁」都是同一件事：跨会话记住用户偏好。我们目前每次规划都是冷启动。→ **新增 `task-user-profile-memory`**：用户偏好画像表（人群/节奏/预算档/常去城市）+ 规划时注入画像摘要（验收：画像 CRUD + 规划注入 + 测试覆盖；不读 .env、不需要新 API key）。
3. **【内容沉淀 · 中优先】地图拖拽编辑对比文章** — 携程「可视化地图拖拽编辑 + 一键导出 Excel」已成国内标配交互；我们 Leaflet 已展示但无拖拽。写一篇发布就绪文章对比「表单生成 vs 对话修订 vs 地图拖拽」三种修订范式的工程代价与体验差异，既沉淀思考又为 `task-map-drag-edit` 铺路（验收：docs/articles/05-map-edit-paradigms.md 存在且完整；不引入计划外代码改动）。
4. **【补功能 · 低优先】行程备选方案（Plan B）** — 马蜂窝「行程备选方案」是行前高频需求：天气/拥堵/临时关闭时一键切换备选。→ 记入 backlog，待 `task-roadtrip-mode` 完成后再评估（本轮只记录不开发，遵守「一个 worker 一个任务」）。
5. **【补功能 · 低优先】多语种攻略输出** — 同程 9 语种、TripGenie 12 语种、飞猪手绘攻略分享都指向入境游/海外用户；我们 i18n 任务（task-i18n-base）已在列，本项并入该任务范围，不新增独立任务。

## 4. 结论（一句话）

国内 OTA 的 AI 助手赢在「数据 + 预订闭环」，但全部是**黑盒推荐 + 单人操作 + 无修订保障**；我们的差异化（多 Agent 透明轨迹、可修订不回滚、质检闭环、真实数据不造假）依然成立，**最该补的是「主动提问」与「跨会话记忆」这两个提升个性化感知的能力**——它们是免费能做到、且与生态型平台不冲突的体验差距。
