## 1. 竞品清单

- **Tripnotes 2.0**（tripnotes-2.webflow.io，回归在线）：10-15 记载「被 Dorsia 收购后关停」，本夜实测 **webflow 站点重新在线**，slogan「AI Copilot for travel」。核心范式仍是「输入自由」：notes/texts/tabs 自动 tag+map+research 成 smart notes；新增 booking 动作（table/ride/RSVP 从 note 内直接预订）、评论家 snippet、公开/私有分享；卖点含 **iOS Live Activities——锁屏常驻下一站**（行中留存经典）。这是「独立规划工具未全灭」的最新鲜证据（FlightPlan 2026 收录其 2.0 / AI copilot：读网页/邮件/PDF 提取行程）。
- **Trip Planner AI**（tripplanner.ai，免费+转出变现）：多城市路线是绝对主卖点（「train then fly to Paris, all optimized for cost」、multi-city 复杂交通/transfer/过夜安排）；**Community Trips 社区行程库**（他人分享行程 → 直接借鉴）；pre-built itineraries 模板出发；价格透明度（exchange rate 提示）+ Booking/GetYourGuide/Viator/Skyscanner 转出；实时价格「Prices & Easy Booking」；road trip 模式（scenic stops/过夜点优化）。界面偏旧但功能密度高。
- **Wonderplan**（wonderplan.ai，完全免费）：零付费墙、PDF 导出、免费模板起点；缺点依旧：单城市、无协作、无地图（评测矩阵 ❌ interactive maps）、「Find a place to stay」仍只是 Booking 首页占位链接。免费模板库是其唯一护城河。
- **Mindtrip**（mindtrip.ai，免费）：2026 最全免费票 + chat 内预订（Flights/Stays）；**Start Anywhere**（网页/社媒/照片/PDF 一键转行程）、receipt 归集（forward receipts@mindtrip.ai）、**Group Chat @Mindtrip**、Events/Collections 收藏夹、Creator Program（内容创作者带货返佣）；地图第一视角 + 8 语言。
- **Layla**（layla.ai，免费核心 + ~$49/年 Premium）：被 Expedia 收购后转「免费规划 + 人类专家代订」；**Multi-Destination Route Map**（欧洲铁路/美西自驾/亚洲跳岛多目的地路线图）、video map 创作者视频叠层、PriceLock 锁价；16 语言声称。行中仍止步前（无今日视图/顺延）。

## 3. 差距 → 行动项（我们可补的差距 / 可借鉴的亮点）

1. **【补功能】公开灵感画廊 / 社区行程库**（Trip Planner AI Community Trips + Mindtrip Inspiration + Wonderplan 模板库三方共识；我们只有私人 favorites 收藏夹）。行动：轻量版「精选行程画廊」——从分享页转化精选（运营侧标记 share token 行程为 featured），首页/灵感页展示精选卡片（目的地/天数/预算档/一句话卖点），点击「以此为基础创建」→ 复制行程为我的（复用 PlanWizard 预填 + 现有 share 只读消费链路，零新凭证）。验收：画廊接口 + 精选标记 + 一键复制创建 + 测试覆盖。
2. **【内容沉淀】Tripnotes 2.0 回归案例补进 14 文**（content-independent-planner-survival）：10-15 论证「独立规划层不死，死的是没有深度的规划层」时 Tripnotes 是「关停」反例；本夜实测其以 note→map 范式回归 + iOS Live Activities 锁屏行中——成为「输入自由 + 行中价值」双支柱的正面案例。行动：14 文章节补「2026 Tripnotes 2.0 回归」段落（关停→重生路径 + 与我们四通道导入/行中今日视图的同构印证），发布清单同步。
3. **【评估候选】行中「锁屏/常驻条」等价物**（Tripnotes iOS Live Activities 亮点，2026 唯一一家做锁屏行中的）。行动：评估 PWA 低成本近似——独立窗口常驻进度条 / 顶部通知横幅 / home screen 快捷状态卡片 vs 工程成本与 iOS/Android 平台差异；评估不过记录降级关单（我们的 WS feed + 未读红点已是基础）。排在 task-trip-event-notify 之后。
4. **【补功能·轻量】模板出发起点强化**（Wonderplan 免费模板 + Trip Planner AI pre-built 同源）：我们有 task-inspiration-mode 灵感推荐，但缺「热门城市模板」深链（用户明确知道目的地时直接拿模板改）。行动：并入 1 的验收可选分支——画廊条目支持「城市模板」形态（inspiration_service 27 目的地知识库直接生成预填模板卡），两个行动项共享画廊 UI。
