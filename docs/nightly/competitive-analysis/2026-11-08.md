## 1. 竞品清单（★=本夜新增/重点）

### 1.1 新入场者（★本夜新增，全部集中在「规划之后」）

- **WanderBuddy**（★2026-11-07 发布，群体行中）：移动端**只做群体出行**——AI 生成可共同编辑的行程、**共享实时地图**（按天钉点）、**自动费用分摊与一键结清**、**站点点投票**、WhatsApp/Instagram 集成、签证要求检查、航班追踪、带实时翻译的语音房。定价：免费首趟（≤10 人、2GB 照片）+ Premium $6.99/月 / $59.99/年 / $100 买断。**这是与我们协作投票 + 费用分摊 + 行中视图最正面撞车的一个**，差异在于它把「群体」当唯一场景、把 IM 当入口。
- **Petrel Voyage**（★2026-11-01 发布，后置整理 = «TripIt 杀手» 叙事）：把**任意格式的预订确认**（邮件/PDF/截图/照片/表格）在 1 分钟内变成日行程；附实时航班状态、**全程离线**、**ICS 日历订阅**、加密证件保险箱、群体费用分摊、行程回顾。免费首趟 / Voyager $49/年 / 单趟 $9.99。**我们 email_import（粘贴文本）+ export_service（仅 JSON）正好卡在它的中间**：输入侧同构、输出侧缺日历与离线。
- **Itinerarly**（★2026-11-06 发布，卢森堡独立开发者）：用户丢入地点 → **自动排最优顺序并计入实时路况** → 步行/驾车逐点引导（iPhone 支持 CarPlay），内置 44 城 134 条免费音频步行导览（5 语）+ AI「Adventure 模式」随机就近玩法。免费、需注册。**「一键最优排序」正是我们 solver_service / reorder_service 已在 main 但没有 UI 入口的能力**。
- **Naviu**（★2026-11-01 发布，日本）：AR 旅行伴侣——城市级 AR 路径叠加、29 语言、基于精确位置的 ask-anything、照片识别、定制行程。行中交互形态的另一种解法（不抢规划入口，抢「走在街上那一刻」）。

### 1.2 巨头与在位者（增量信号）

- **Airbnb**（★Q3 电话会 2026-11-05，此前 11-06 只拿到「1H2027 上线」标题流，本夜补到设计细节）：Chesky 明说 **「聊天窗口是规划旅行的错误形态」**——行程涉及地图、照片、日期和群体决策，所以要做**可视化、协作式、由旅行专用屏幕与组件拼成的 agent**（而非 chatbot）；将通过 **MCP** 连接 Airbnb 之外的服务；Q3 营收 **$4.87B（+19%）**，$12B 回购；并直言**通用 AI agent（点名 Meta Muse）给 Airbnb 带来的流量很少、成交更少**。→ 对我们的直接含义：**我们的表单 + 地图 + 按日卡片 + diff 预览这条界面路线，与 Airbnb 的判断同向**；「通用 chatbot 顺手做旅行」并不构成入口威胁，构成威胁的是「专用界面 + 自有库存」。
- **Google**（★本夜核验细节）：AI Mode 里的 **Canvas 日行程视图**（可视化行程板，US-only）已在灰度；官方 blog 明确「未来可在 AI Mode 内完成机票/酒店预订（与合作伙伴一起）」。同时 Gemini App 把自定义 Gems 换成 **skills**——个人账号 **2026-11-17 起 Gems 变只读、12-17 移除**。→ 平台侧「能力名词」在快速重写，第三方不要把产品价值押在某个平台概念上。
- **Mindtrip**（增量）：已在 chat 内**直接订机票与酒店**（2025 只有研究/收藏）；**2026-09-30 Personal Travel Assistant** 记住偏好并持续盯票价/房价/活动；POI 库 1100 万+。→ 「免费 + 佣金」模型下，**它已不是纯规划层**。
- **Wanderlog**（★关键增量，直接服务本夜额度治理评估）：免费档 **AI 助手按条数封顶**——2026-02 实测「每趟 5 条」，2026-10-05 打开新会话显示 **「10 free messages left」**；**无限 AI 是 Pro（$39.99/年）** 的功能，Pro 另含路线优化、离线、Gmail 自动扫描、导出 Google Maps。**免费档的行程数量与协作者人数永不限制**（help center 明确）。→ 行业事实标准：**限制 LLM 用量，不限制数据量与协作**。
- **Layla**（收购后形态，增量）：Expedia 收购后转向 **「AI 规划 + 真人 Travel Expert 成交」** 的混合模式，官网主打「AI plans it. Your travel advisor makes it unforgettable.」；Pro $49.99/年，长行程**免费档已基本没有意义**。→ 「免费规划 + 付费成交」是独立工具被收编后的常见归宿。
- **Cape Town Tourism**（★2026-11-05 宣布，DMO 侧新增）：免费 AI 行程规划器，**2027-01 上线**，第二阶段（暑期）加机票/住宿预订；官方口径强调「用本地专业度做出比 ChatGPT 更地道、超出必去景点的行程」。→ DMO 供给合作（Mindtrip 路线）继续扩散到城市旅游局。
- **MonkeyTravel / Stippl**（沿用）：MonkeyTravel 行中四键（完成/跳过/迟到顺延/就近替换）+ 打包清单；Stippl 主打「行程+预算+打包+分摊」一体化。
- **量级参考**：Allianz Partners 调查（Hotel Dive 2026-07-23）——**37% 美国旅客已用 AI 规划旅行**，并期待全程「快、直觉、移动优先」。

## 3. 差距 → 行动项

1. **【本夜执行】预订中立性显性化**（task-booking-neutrality-eval，已在队列）——本夜新增三组证据：Airbnb 明确自建 agent（自营库存）、Mindtrip 已 chat 内成交、Layla 被收购后只卖自家打包行程。**「免费规划 + 中立跳转、不碰库存与佣金」正在从默认变成稀缺位**。行动：评估 → 最小版把中立立场写进落地页 + README（零凭证、零新依赖），并作为 15 文后续内容的叙事锚点。
2. **【本夜执行】登录用户额度治理**（task-quota-governance-eval，已在队列）——**Wanderlog 已给出行业事实标准：限制 LLM 调用条数，不限制行程数与协作人数**（免费 5–10 条 / Pro 无限），Hilton CIO 也在公开谈 tokenomics。行动：评估矩阵 + 最小版「24h 规划次数计数 + 软提示」（零表零迁移，硬限流仍需用户立项）。
3. **【本夜执行】13 文《信任缺口》补 11 月实证**（content-trust-gap-update，已在队列）——新增素材：Airbnb「通用 agent 带来的流量很少、成交更少」（信任/转化双向证据）、Allianz 37% 已用 AI 规划（渗透率）、Cape Town Tourism 主打「本地专业度 > ChatGPT」（供给真实度诉求）。
4. **【新增·补功能】task-ics-export**：行程导出补 **ICS 日历订阅**（Petrel Voyage 的差异化项；我们 `export_service` 目前只有 JSON，导出自由缺「落到日历」这一步）。零凭证：由 plan days/stops 生成 VEVENT（全天事件 + 站点点位作 LOCATION），owner 与 share token 双路径，与 JSON 导出共用序列化口径。验收：ICS 结构合法（VEVENT/DTSTART 日期 + SUMMARY + LOCATION）、双路径可用、令牌零泄漏、测试覆盖。→ **行动项 slug：task-ics-export**
5. **【新增·补功能】task-auto-optimize-cta**：「按最优顺序重排」一键入口——`solver_service.rank_candidates` / `reorder_service.reorder_commit` 已在 main，但详情页只有单点上移/下移（10-29 遗留 `useDragEdit` 未接入）。Itinerarly 证明「用户不想手动拖，想让工具直接给顺序」。最小版：某日卡片加「优化顺序」按钮 → 调既有 reorder 端点 → 展示 diff 摘要（不放宽任何 Gate 约束）。验收：按钮出现/成功/自驾冲突 400 内联提示 + build 通过 + 后端既有测试回归。→ **行动项 slug：task-auto-optimize-cta**
6. **【备忘·不排期】群体场景对标**：WanderBuddy 把「群体」当唯一场景（IM 入口 + 签证检查 + 语音房 + 一键结清）。我们已有投票/分摊/共享地图，缺 **IM 入口（WhatsApp/IG）** 与 **签证规则库**；IM 入口涉及第三方平台合规与凭证，签证规则库是纯规则但覆盖面大（国籍×目的地），两项都不在本夜队列，登记备忘待用户立项。
