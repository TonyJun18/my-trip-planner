## 一、竞品清单（本夜聚焦 7 款 = 4 海外头部 + 2 预订后整理 + 1 已退场参照）

1. **Mindtrip**（mindtrip.ai，硅谷）—— 2026-05-06 上线 **Mindtrip Flights**：行业首个「对话内完成机票搜索/比价/支付」的 agentic 预订体验，Sabre Mosaic（420+ 航司实时库存/占座）提供交易轨、PayPal 对话内结账（含 BNPL Pay in 4 / Pay Monthly），无跳转第三方站。规划本身免费无 paywall、视觉精美、数据与预订集成最深。短板：仅机票（酒店下一阶段）、需要 Sabre/PayPal 级供应链——小团队无法复制；规划可修订性弱于专门工具。
2. **Layla（现属 Expedia Group）**（layla.ai，柏林）—— 2026-07-31 Expedia Group 官宣收购（Skift 独家：2023 创立、~25 人、~€5M 融资、金额未披露、继续 standalone 运营）。收购加速 Expedia 多智能体架构（此前 deprioritize Romie，转向 specialized agents）。核心：对话式规划 + 实时价格（Skyscanner/Booking.com）+ PriceLock 提醒，免费起步、Premium $49/年；1.1M+ 行程、自报 4.9 星。短板：被并购后推荐中立性存疑（用户会问「推荐是否偏向 Expedia 库存」）；Trustpilot 4.0/86 评，口碑基数薄。
3. **Wonderplan**（wonderplan.ai，马来西亚）—— 纯免费免登录、表单输入（目的地/日期/预算/同行人）约 60 秒出日计划、PDF 导出、增删重排；无协作无预订、无实时安全更新，偏主流景点、结构僵硬。仍是「零门槛第一稿」标杆。
4. **iPlan.ai**（iplan.ai）—— 移动优先快速行程；免费下载、AI 从 $3.99 起；应用内仅 Tours 预订；基础分享/协作；8 语；**无实时数据**。预算偏差 20-30% 的口碑问题（09-26 已记）依然是「诚实估算」的反面教材。
5. **AiGo**（theaigo.co）—— 免费 30 credits/月（基础行程+预算追踪+3 个行程）→ 300 credits/月（先进模型/无限行程/机票搜索）→ 3000 credits/月（实时协作/酒店活动预订/语音输入/离线）。订阅制挤压免费层；协作+离线+截图导入齐全，但其「免费额度经济」验证了我们开源/自托管免费的价值主张。
6. **iGo / TripNoted（预订后整理双子）** —— iGo：转发/粘贴预订确认邮件（Gmail 连接、航班号/酒店地址/确认码/费用自动提取）→ 彩色地图标记、拖拽重排、预算 Spent/Budget/Remaining 自动更新、离线存取证件、Google Calendar 导出。TripNoted（iOS，2026-08 首发，1.0.20 上线 **social links → Ideas on map → start trips**）：把社交分享链接变成地图上的 Idea 再开行程。共同点：**post-booking 范式**（Tripnotes 当年的定位），从「用户已有的真实预订」反推行程管理，零输入成本。
7. **Troupe / TRIPTI.ai（退场参照组）** —— JetBlue 旗下群组规划 Troupe 于 2026-06 确认倒闭（域名不解析、双商店下架、无官方公告）；替代者 TRIPTI.ai 的关键架构洞见：**「多数 commit 即锁定日期，不要求全员同意」**（progressive vs consensus-first）——「不回复的那个人不冻结整个行程」。JetBlue 都做不活的群组规划，恰恰说明协作刚需持续存在（Wanderlog 免费协作、MonkeyTravel 群组投票仍在验证），但产品必须轻、必须渐进。

> 退场时间线（本夜整理）：Tripnotes 2023-12 被 Dorsia 收购后关停（Skift 2024-01 报道，ChatGPT 起家、病毒式 demo、融资冰点）→ Layla 2026-07 被 Expedia 收购继续独立运营 → Mindtrip 2026-05 实现对话内机票成交 → Troupe 2026-06 无声倒闭。**独立规划工具的剧本从来只有两本：被巨头整合，或小而锋利地活。**

## 三、我们可补的差距 / 可借鉴的亮点（本夜 4 条行动项 + 2 条借鉴）

### 差距 → 行动项

1. **【补功能】预订后整理最小版——粘贴预订确认邮件文本 → 提取并入行程（iGo/TripNoted post-booking 范式）**
   现状：note-import 只处理「攻略笔记文本」；用户手里真正高价值的结构化信息是**预订确认邮件**（航班号/酒店/日期/金额已经被商家格式化好）。iGo「转发邮件→自动提取」需要 Gmail OAuth（凭证级集成，暂不做），但 iGo 也支持「**直接粘贴邮件文本**」——零凭证，与我们 note_import 的敌意输入处理管线完全同构。
   → 行动项：`task-email-import`：行程创建页新增「粘贴预订确认邮件文本」→ 复用 note_import 结构化提取，识别航班/酒店/活动条目（关键字段：日期时间/名称/地址/确认码/金额）→ 候选勾选并入行程，贴回 note-import 的防注入处理（只提取、不执行、不污染 system prompt）。验收：粘贴典型航司/酒店确认邮件可生成结构化条目 + 金额可进预算视图 + 恶意注入文本按敌意输入处理 + 测试覆盖。（排在 task-screenshot-import 之后，管线复用度高、工程量小）

2. **【内容沉淀】《终局剧本：当 agentic 预订已经成交、独立工具已被收购——规划层还剩什么》**
   本夜四个信号串成一根线：Mindtrip Flights（2026-05，Sabre+PayPal 对话内机票成交，行业首个「从灵感直接到交易不出聊天框」）→ Expedia×Layla 官宣（2026-07，规划工具并入预订巨头，Romie 退位）→ Tripnotes 被收购关停（2023-12）→ Troupe 无声倒闭（2026-06）。结论：**预订层正在「对话内成交 + 巨头整合」双轨加速，独立工具要么被整合、要么小而锋利地活**；小而锋利的活法 = 可修订（diff）、可验证（质检 trace）、可协作、可导出、预算诚实、输入自由（笔记/截图/邮件文本）——全部是我们已落地或队列内的能力，是 07/08 文的「终局篇」。
   → 行动项：`content-agentic-booking-endgame`：写一篇发布就绪文章（docs/articles/10-*.md），以 Mindtrip Flights 与 Expedia×Layla 为引、Tripnotes/Troupe 退场为对照，论证「规划层」作为独立层的生存策略与我们的反例实践；发布清单补卡片。

3. **【补功能·队列内验收升级】task-trip-collab-vote 增加「渐进式推进」验收项（TRIPTI.ai vs Troupe 教训）**
   Troupe 倒闭与 TRIPTI.ai 的立身之本都在同一处：群组规划**不能共识优先**——「等全员同意才锁日期」会冻结行程，多数 commit 即推进才是能活的产品。我们的站点投票/评论（task-trip-collab-vote，队列中）应把「渐进式」写进验收：投票/确认达到 ≥50% 受邀成员即可标记「小组一致」，未响应成员不阻塞后续（日程可先锁定、后补确认）。
   → 更新 `task-trip-collab-vote` 验收标准：加入「多数即推进、不响应不阻塞」的渐进式协作语义 + 测试覆盖。（不改任务主体，仅升级验收口径）

4. **【补功能·队列内验收升级】task-screenshot-import 增加「社交分享链接提取」轻量分支（TripNoted social link → Idea）**
   TripNoted 1.0.20 的亮点：把社交分享链接变成地图上的 Idea 再开行程——与截图导入姊妹同属「输入范式」。截图导入管线里顺带支持「粘贴公开可读的分享链接 → 尝试提取页面结构化信息（标题/图片/内容）」，失败即降级为链接收藏，不阻断主流程。
   → 更新 `task-screenshot-import` 验收标准：截图 OCR 为主，社交链接提取为可选分支（公开可读才抓取，失败静默降级，校验输出 schema 防注入）。

### 亮点借鉴（不建任务，记录在案）

- **Mindtrip × Sabre × PayPal 三层分工**（conversational UI / inventory API / agent-aware payment）：预订层是「库存 + 支付」资本密集型生意，三层里没有一层是小团队能自建的——这正是独立规划层不该碰预订的结构性理由；若未来做「参考方案可跳转预订」，也保持 UI+结构化推荐与交易轨分离。
- **iGo 预算自动更新（Spent/Budget/Remaining）**：从真实预订金额反推预算实际值——我们的预算视图可借鉴「估算 vs 实际」联动（task-hotel-budget 口径标注已铺路；顺着 task-email-import 的金额提取即可让「实际」开始有数据来源）。
