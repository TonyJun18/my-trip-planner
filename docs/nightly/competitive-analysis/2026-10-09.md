## 一、结论先行

1. **竞品格局没有反转，但「起点体验」的军备竞赛在升级**。Mindtrip 主打 Start Anywhere（从链接/截图/社交帖/PDF 起步，不必先定目的地）+ 实时地图 + 组队投票；Layla 主打「AI 规划 + 真人专家混合」与五问 checklist 低摩擦起点；Wonderplan 坚持免费 + PDF 离线，纯规划不碰预订。三者共同信号：**「免注册、低起点、先出东西」是获客门槛**，而我们把重心放在了生成质量与修订闭环上，入口摩擦相对偏大。
2. **iPlan.ai 的营业时间/游玩时长翻车 = 我们「诚实度」维度可以继续赢的实锤**。今夜抓取到 iPlan.ai 应用商店差评原文：把相距 1 小时的两个城市站点交错排进一天、删除景点无效、建议安排「到达时已闭馆 25 分钟」的景点——这正面印证我们 09-26 已定位的价格真实度哲学可以扩展为**时间真实度**（营业时间/游玩时长校验）。
3. **三件已具备的差异化仍成立**：①自驾经停优化+避免折返（TripPlanner AI 招牌，我们 DrivingGate+高德 source=amap 已落地）；②质检透明 trace（全场唯一）；③免费+自托管开源（Wonderplan 也在免费，但无开源无 trace）。

## 二、竞品清单（今夜真实抓取，每家 2-3 句）

### 1. Mindtrip（mindtrip.com，美）
AI 旅行规划头部玩家，核心是 1100 万+ POI 数据库 + 4 万本地达人输入（而非纯模型生成）做推荐地基；对话式规划 + 实时交互地图（每个建议自动落 pin，照片/评分/一句话），组队实时 co-edit + 投票。Start Anywhere 允许从博客链接/截图/社交帖/PDF 起步规划；2026-05 起对话内直订机票（Sabre+PayPal，酒店经 Expedia/Hotels.com、活动经 Viator），iOS Magic Camera 行程中识别地标+翻译。免费层约 50 条 AI 消息/月，Pro $9.99/月；短板是 POI 库欧美为主（第比利斯等小众目的地掉回 ChatGPT 水平）、部分门票仍跳外站。

### 2. Layla（layla.ai，德）
「AI 旅行代理 + 真人专家混合」模式，宣称 200 万+ 行程、平均 4.9★；五问 checklist 起步（去哪/从哪/和谁/何时/要什么→generate），AI 对话内实时价格与可用性，支持 16 语、多城市路由图、创作者视频地图（看视频种草→一键加入行程）；2026-07 被 Expedia 收购官宣（预订层整合信号）。免费层 + Premium $49/年（实时票价提醒在付费层）；短板是活人专家服务依赖订阅变现，与「免费规划层」定位不同。

### 3. Wonderplan（wonderplan.ai，美）
免费纯规划工具：「至少目前免费」；表单式输入（目的地/日期/预算/兴趣）→ 个性化行程，单页内直接改（重排/增删/丢弃），住宿推荐 + 酒店搜索 + Deals，行程可收藏，PDF 下载离线。无预订、无真实价格、无协作——Layla 自家对比表里定位「fast free itineraries, plan-only」。短板：功能薄、免费可持续性不明（"at least for now" 自家原话）。

### 4. iPlan.ai（iplan.ai，加）
2 万+ 城市地点库，强调「景点按地理位置聚类 + 真实游玩/车程时长」排日程（分钟级），行程地图视图（类似 Roadtrippers/Wanderlog 免费版）、跳到 Google/Apple/Waze 导航、手动自由编辑/重排/收藏、可离线、可私密/公开分享。模式：**手动规划免费，AI 生成行程订阅付费**（Pro Rp 69k 档）。短板直接写进应用商店差评：AI 把相距 1 小时的跨城站点交替排进一天、删除无效、推荐「到达即闭馆」的景点、付费口径混乱——**质量口碑翻车现场**，是我们的反面教材。

### 5. TripPlanner AI（tripplanner.ai，美）
自驾/公路旅行差异化：「经停优化 + 避免折返」——AI 建议沿途经停点、观景点、过夜点，避免单段开太久；行程「结构化+自由度」：每天 1-2 个必看高亮 + 可选活动 + 冗余时间；支持天气/心情变化实时重排。免费有限额。短板：既定目的地导向，无免登录即用，无协作/预订。

> 参照：Tripnotes.ai（2023-12 关停）——「笔记→行程」范式先行者，留下市场窗口；其社交链接→行程范式已被 Mindtrip Start Anywhere 与我们的 link-import 承接。

## 四、3-5 条「差距 → 行动项」（本夜 4 补功能 + 1 内容沉淀）

### 差距 1 → 行动项（补功能）：灵感优先起点——「还没想好去哪」模式（Mindtrip Start Anywhere / Layla checklist 验证）
- **证据**：Mindtrip 招牌 Start Anywhere 可从「模糊情绪/单个活动/粗略预算」起步；Layla 五问首问是「Where to —— Let me inspire you if you don't know」；两家都把「先定目的地」的摩擦拆掉。我们创建表单目前先定目的地+日期，灵感流缺失。
- **行动项**：`task-inspiration-mode`：创建规划页加「还没想好去哪」入口——填预算档/兴趣标签/季节/同行人数 → 推荐 3-5 个目的地卡片（一句话理由 + 参考玩法 + 预估日均预算）→ 点选后预填创建表单进入现有规划流程。纯规则+LLM 组装，无新 API key。
- 验收：前端灵感入口 + 推荐卡片 + 选定预填 + 后端推荐接口 + 测试覆盖；build 通过。

### 差距 2 → 行动项（补功能）：营业时间/游玩时长真实度（iPlan.ai 闭馆翻车 = 反面教材）
- **证据**：iPlan.ai 应用商店差评原文「建议 2 小时参观时长，但该景点在到达 25 分钟后闭馆」「跨城站点交错排一天」；我们已用「价格真实度（城市基准价+口径标注）」建立诚实预算口碑，**时间维度是同一哲学的自然扩展**——排程校验闭馆到达/单日过饱和。
- **行动项**：`task-open-hours-check`：POI 类目基准营业时段表 + 建议游玩时长表（规则库，先不接外部营业时间 API）→ 规划/修订排程时校验「闭馆到达」「单日游玩时长过饱和」，产出 warning 并附调整建议（复用质检与 ReviseCritic feedback 通道）。
- 验收：排程校验 warning + 建议 + 测试覆盖（含闭馆/过饱和/正常三路径）+ 前端质检卡透出。

### 差距 3 → 行动项（补功能）：地图 pin 信息卡片与当日路线视觉化（Mindtrip 地图交互亮点）
- **证据**：Mindtrip 每个建议自动落 pin，点击即见照片/评分/一句话描述，行程以地图为第一视图；我们的 TripMap 已有拖拽修订（main）+ 路线，但 marker 无信息卡片、当日站点无自动连线，信息密度差距明显。
- **行动项**：`task-map-pin-cards`：TripMap marker 点击弹出信息卡（名称/一句话理由/评分/预算标注/图片占位）+ 按日连线当日站点。纯前端。
- 验收：marker 点击卡片 + 当日连线 + 移动端可用 + build 通过；桌面/移动回归。

### 差距 4 → 行动项（补功能，候选评估）：免登录试用规划（Wonderplan/Mindtrip 免注册即用）
- **证据**：Wonderplan 免费无门槛即用；Mindtrip 核心规划免 signup（30 秒出可分享行程）；我们创建行程需登录，分享页 token 免登录是「消费端」免登，「生产端」仍有门槛。
- **行动项**：`task-guest-trial`（候选）：guest 创建行程（本地暂存，注册后凭 token 接管），限制不可分享/不可持久化。**先评估**：guest 数据安全、成本滥用（LLM 调用）、与现有 share_token 语义的边界——评估不过则降级为只记录,不实现。
- 验收：评估记录 + （若通过）guest 建行程/注册接管/提示文案/测试覆盖。
