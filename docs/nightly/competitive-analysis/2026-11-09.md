## 1. 竞品清单（★=本夜新增/重点）

### 1.1 新入场者（★本夜新增）

- **Iter**（★2026-11-02 发布，照片/视频入口）：**不用打字**——用相册照片 + 短视频 + 几个快问快答建立旅行风格画像（常去小众巷子 vs 热门景点），生成按天的个性化行程；11-02 版新增**单点编辑**（不满意的餐厅/景点单独换，不用重做整趟）。免费，iOS/Android。创始人对 Upgraded Points 明说**不做里程/比价**——它的切口是「发现 + 匹配偏好」而非省钱。→ 与我们的**灵感入口 + 四通道导入**正面撞车，但它把「输入」从文本/链接推进到了**相册本身**。
- **Journelyx**（★2026-11-08 更新 v3.2.1，Wandertech Labs）：主打**离线**——矢量地图瓦片预下载（每国约 85MB）、无网 GPS 导航（8 米精度）、离线搜索；**天气感知规划**（15 天预报，降雨 >60% 自动给室内替代方案，紫外线/日出日落影响打包建议）；**多币种费用追踪**（实时汇率 6h 更新、12 类自动分类、24h 前超预算预警）；免费档 **5 次 AI 行程/月** + 14 天 premium 试用。自称训练于 240 万真实行程。→ 「免费额度 + 离线 + 天气」三个点的组合拳，付费墙后是行中完整度。
- **Vybego**（★2026-11-02 发布，Product Hunt #1 of the Day）：**一句式**输入 → **路线优化**的按天行程（停留/餐饮/体验按预算与风格匹配），卖点是「不要在 10 个 tab 里拼行程，一次给全」。免费，Web。→ 与我们的**一键最优排序**（11-08 已上线）同一叙事，它把「route-optimized」写进定位语。
- **DVGO**（★2026-11-01 发布，跨境/供应商侧）：一句话 → 澄清目的/日期/人数/预算 → 行程 + **透明预算（含/不含清单）** → 推荐服务商 → **RFQ 询价 → 在线付款**。本质是「AI 规划 + 撮合交易」的 B 端闭环，预算透明度做成了卖点（「AI 预算仅供参考，最终以服务商报价为准」的诚实口径与我们的 basis 标注同构）。
- **Nanajee**（★2026-11-05 发布）：一句话描述 → 约 1 分钟出**含机票/酒店估价**的按天行程，可对话修改、分享、对接合作方预订。低热度（1 upvote）但代表「一句话 → 含钱行程」的标准模板。

### 1.2 在位者与巨头（增量信号）

- **TripGenie / 携程**（★Google Cloud 案例研究，本夜拿到升级细节）：2026 年上线**出境 eSIM + 景点门票代理预订**；技术底座换 **Gemini 3**（多约束长上下文推理）+ **Agent Search on Gemini 做检索接地**（回复锚定可验证信息源，防幻觉/过时开放时间）；定位从「能回答旅行问题的聊天机器人」升级为「行前灵感/比价 → 行中沟通/路线确认 → 行后售后」全时旅伴；官方明确「先在低风险场景验证代理预订，关键节点保持用户知情和掌控」。效果：**3x 用户增长 + 7 天留存 +73%**。→ 两个可借鉴点：①**接地检索防幻觉**（与我们 basis/质检口径同思路，但它是搜索引擎级接地，我们是规则库+标注）；②「知情与掌控」= 我们的两阶段 HITL/revise 预览同构，巨头把它当作**信任建设的第一原则**写进案例。
- **圆周旅迹（Pi Travel）**（★知乎 2026 趋势报告 + 163 五工具实测）：**「一键抄作业」**——粘贴小红书/攻略链接 → AI 提取地点、解析时间顺序、地图排线，5 分钟替代手动 30 分钟；**对话式修改**（「第二天太挤，博物馆挪到第四天」一句话重排 + 历史改动保留）；地图点位按地理位置聚类排线；**每段交通时长标注 + 出行日天气标注**在行程旁；分享链接免 App 打开；**多人实时协作**（A 加餐厅 B 调顺序 C 标伴手礼，实时同步）。短板：无预订、冷门点位详情缺失、境外数据密度弱。→ 与我们五通道导入/对话修订/ShareView 几乎逐点对应，证明**「把收藏变成行程」是 2026 中文市场最大增量**（攻略过载 30+ 篇收藏、整合成本翻 4 倍）。
- **马蜂窝 AI 行程助手**（★163 实测）：内容库是真的（「适合老人的成都点位」社区有现成沉淀），工具是糙的——**修改非对话式**、手动删加后不重排。不可替代处 = 避雷信息/真实游记密度。→ 反面对照：我们质检（闭馆/体力/餐饮锚定）在「避雷」上替社区内容做了工程化兜底，但**真实用户反馈密度**仍是零（无社区）。
- **Mindtrip**（沿用）：2026-09-30 Personal Travel Assistant（记住偏好、跨行程记忆、盯着票价）、chat 内直订机票/酒店（Sabre+PayPal）、1100 万 POI。本夜横评补充：**持久预算条**（增删活动实时更新）+ 按天计划/实时地图组织结果。→ 「预算条常驻」是规划器交互微创新，我们预算在详情页卡片、非规划主流程常驻。
- **Layla / Wonderplan / Wanderlog / Stippl**（沿用，无重大增量）：Layla 收购后「AI 规划 + 真人成交」、Pro $49.99/年；Wonderplan 全免费 + PDF 导出 + 可拖拽；Wanderlog 免费 AI 5–10 条封顶/Pro $39.99 无限；Stippl 行程+预算+打包+分摊免费档标配。
- **通用聊天器**（横评共识）：ChatGPT/Claude/Gemini 仍是「研究 + 快速草稿」首选，但**缺地图/照片/协作/预订专用件**——与 Airbnb Q3「chat 窗口是错误形态」判断互相印证。

## 3. 差距 → 行动项

1. **【新增·候选评估】task-weather-gate-eval：天气感知排程**（backend）——Journelyx 把「15 天预报 + 降雨 >60% 自动室内替代」做成付费卖点，圆周旅迹也在行程日旁标天气；我们 agent 规划期已有 query_weather（高德 AMAP 或降级 wttr.in，零常态化成本）但**不进排程约束、行中无天气展示**。评估最小版：①排程校验注入天气 warning（雨天/酷暑日 → 室内替代建议 + 复用 time_validation/质检通道，basis=rule_based 诚实标注）；②live 快照加当日天气卡（复用 wttr.in 预报，零凭证）。可行则最小版后端 + 测试；窗口不足或「预报不可作硬约束」评估不过则记录降级关单。→ **slug：task-weather-gate-eval**
2. **【新增·候选评估】task-multi-currency-expense-eval：多币种费用追踪**（backend）——Journelyx 多币种实时汇率 + 自动分类 + 超预算预警（我们 expense 仅单币种 trip.currency 默认 CNY、手动分类）。零凭证评估：记账时输入「当地金额 + 币种 + （可选）汇率」→ 按 trip.currency 折算汇总（汇率规则库/用户填，禁引实时汇率 API 凭证书）；预算预警（24h 前）明确不做（需常驻任务）。可行则最小版 + 测试，否则关单。→ **slug：task-multi-currency-expense-eval**
3. **【新增·候选评估】task-photo-import-eval：相册照片 → 行程候补**（backend）——Iter 的差异化入口（照片/视频→偏好→行程）；我们截图导入要求用户主动截图，相册批量是「零额外动作」输入。评估零凭证最小版：单张照片 EXIF（拍摄时间 + GPS）→ 地点候补（反向地理编码需凭证则降级为「仅时间 + 用户填地点」）；隐私/平台授权是主要评估点。大概率评估不过（相册访问授权 + 反向地理编码凭证），记录降级关单即可（铁律 9/10）。→ **slug：task-photo-import-eval**
4. **【素材·内容沉淀候选】「知情与掌控」信任叙事补强**——TripGenie 官方把「关键节点保持用户知情和掌控」当信任建设第一原则（Google Cloud 案例），Mindtrip「预算条常驻」是规划交互微创新。可并入既有 13 文《信任缺口》后续更新或 15 文叙事（巨头用「接地检索」防幻觉 = 我们 basis/质检的搜索引擎级版本；我们的两阶段 HITL 与 revoke 预览正是同一原则的工程实现，可写成一节「巨头补课：他们开始抄我们的作业」）。不单独立项，登记素材。
5. **【备忘·不排期】真实用户反馈密度**——马蜂窝「避雷信息/真实游记密度」是内容侧唯一护城河；我们 15 篇深度文章 + 画廊冷启动 3 条，但零 UGC。与 task-gallery-community-v3 前置条件（内容量）同源，继续排队，需用户按内容量数据立项。
