## 0. 一句话结论

**独立 AI 规划器的「独立」越来越难成立**：Google Maps 直接内建行程生成（Ask Maps，11-16 官宣，欧洲 30 国）把规划吞进地图主流程；字节跳动用「找店」地图闭环把推荐→团购→导航收拢进单一对话（11-16）；携程 Trip.Planner 规划来华行程占 35% 且 TripGenie 辅助订单同比 +400%（11-19 峰会）。与此同时，新入局者 Everway 把「行前整理」（确认单归集、签证检查、免费取消截止提醒、MCP 输出）做成差异化——**独立工具的新缝隙不在「再生成一份行程」，而在「行程生成之后的整理、提醒与输出」**。

## 一、竞品清单（6 个）

**1. Google Maps — Ask Maps 行程生成（11-16 官宣，欧洲 30 国）**
Google 把 AI 行程生成直接放进地图：描述需求（节日购物一日游 → 三日海岸自驾）→ 生成按天编排日程，每站带本地建议 + 编号地图图钉；出发时显示实时路况/营业状态/「下一站氛围」；对话内可调整（「沿途加一个观景点」）；可与亲友分享、桌面端导出 Google Docs；Ask Maps 另覆盖预约查找与已保存列表搜索（unite.ai / wuaishare 摘 Google 官方博客，2026-11-16）。**信号：地图即规划器——规划不再需要独立 App，巨头把「生成→查看→改→导」全流程嵌进地图。**

**2. 字节跳动 — 豆包「找店」地图闭环 + 新个人 AI 助手（Spell）**
豆包 App 上线「找店」：对话流内原生渲染交互式地图，匹配商家彩色坐标点 + 距离/营业状态/大众评分，点击门店图标一键直达团购套餐购买与到店导航——信息获取、消费决策、支付交易、物理履约收拢于单一对话（paooo.com 深度拆解，2026-11-16）。另据 Bloomberg 11 月报道，字节筹备对标 Meta Muse 的新个人 AI 助手（内部代号 Spell），张一鸣亲自介绍；豆包 4.19 亿 MAU（同比 +143.6%）但「对话结束任务就终止」是形态边界（techritual，2026-11-12）。**信号：通用 agent 的本地生活/旅行形态 = 对话 + 地图 + 交易闭环。**

**3. 携程 — Trip.Planner / TripGenie（11-19 全球伙伴峰会，悉尼）**
梁建章峰会发言把「行程规划」列为人未被 AI 替代的核心价值之一：国内版携程行程规划、海外版 Trip.Planner——目的地/同行人/天数/节奏 → 逐日行程，地图与卡片双视图，随时改、改完直接接预订；复杂需求交人工定制师。数据：Trip.Planner 用户约 35% 在规划来华行程，活跃用户占比提升超 21%；TripGenie 辅助产生订单 Q2 同比约 +400%（sina finance，2026-11-19）。**信号：OTA 把「AI 规划」做成自家漏斗第一层——规划免费、转化到交易；人工定制师兜底与 Layla 人类专家同构。**

**4. Mindtrip（mindtrip.ai）**
2026 头部独立工具标准姿势确认：**免费即全功能**（无付费层、无消息限制，11M+ POI、Start Anywhere 链接/照片/视频→行程、群聊协作、@Mindtrip 平衡偏好、票务 Sabre 对话内成交 5 月起、Priceline/Viator 合作伙伴预订、记忆画像「Aisle seat, always」+ 盯价 agents 9-30 发布）；iOS 版 4.7★/855 评分。短板（Jotform 7 月横测）：「sometimes inaccurate, clunky filtering」「not great with nuance」（vidtrip.app 深度评测 2026-11 + diginomad/highlights/mira 多源，检索于 2026-11-20）。**信号：免费 + 佣金 + 记忆画像成为头部独立工具标配；质检仍是公认短板。**

**5. Layla（layla.ai，Expedia 旗下）**
11-18 已记「收购后两转向」，本夜多源确认「规划 10 月起免费化」：规划免费（无订阅/无规划费），真人 Travel Expert 检查并代订（酒店/航班/接送/活动），建议最低预算 €100/人/晚，WhatsApp 行中支持；App Store 4.7★；付费层收窄为 Premium ~$9.99/月或 $49.99/年（live pricing + fare-drop alerts）（diginomad / gowithcarmen / aipicksy / mira，检索于 2026-11-20）。**信号：免费化成为收购后默认；「AI 初稿 + 人类收尾」模式固化。**

**6. Everway（Product Hunt，11 月中旬 launch）**——本夜最大新发现
「行前整理」型产品：把各渠道确认单转发到行程私有地址（forward each booking to your trip's private address）→ AI 归集成一份全组共享行程；**检查每位旅行者签证/护照规则**；**盯酒店价格**；**免费取消截止前提醒**（reminds you before free cancellation ends）；确认单/预订号/费用集中一处；无酒店加价；只看到你转发的数据；**提供 MCP 接口**（连 Claude/ChatGPT/Cursor 问「本次旅行总花费」）；$49/年 Pro（launch 价 $29），首行程免费无卡（Product Hunt p/everway，2026-11-中旬）。**信号：行前整理的四个差异点（确认单归集/签证/免费取消截止/MCP 输出）我们全部没有。**

## 三、差距 → 行动项（全部先入 §2 候选池，手册 §5 维持规则）

**G1.【候选评估·backend+frontend】task-free-cancel-deadline-eval：免费取消截止提醒** — 证据：Everway 差异点「reminds you before free cancellation ends」（PH，11 月中旬）；我们 TripBooking 状态机有 cancelled 但无「免费取消截止日」字段，booking_rhythm hotel 规则只有静态「入住前 7 天建议复核取消政策」（_HOTEL_CANCEL_CHECK_DAYS=7，note 文案），无截止日、无倒计时、无提醒。评估最小版（零凭证）：TripBooking 增 free_cancel_deadline（可选，用户回填确认单时录入）→ bookings 列表/节奏卡 days_until 倒计时（复用 11-12 台账倒计时模式）+ 截止前 N 天行程内事件提醒（复用 trip_events + 通知链路，与 task-trip-event-notify 同构）。可行则最小版 + 测试（录入/倒计时/到期不产出/不编造四路径）；不可行记降级关单。

**G2.【候选评估·backend】task-confirmation-batch-import-eval：多封确认单批量归集** — 证据：Everway「forward each booking to your trip's private address → AI 归集成行程」；我们 email_import 是单条粘贴文本解析（零凭证同构），无「多封合并归集」批次形态；私有邮箱地址归集需邮件接收基础设施（域名 + MX + 收取），超出零凭证边界明确不做。评估最小版：粘贴区多封确认邮件（分隔符/多段）→ 逐段复用 email_import 解析 → 候选合并去重（与 screenshot 批量 OCR 合并同构）；可行则最小版 + 测试；不可行记降级关单（维持单条粘贴）。

**G3.【候选评估·backend】task-visa-rules-eval：签证/护照规则检查** — 证据：Everway「checks visa and passport rules for each traveller」；我们零签证能力（全仓 grep visa 仅文案 excludedList 标签命中）。评估数据源矩阵：①静态规则库（中国护照免签/落地签/电子签列表，零凭证但覆盖面大、官方政策更新需运营维护、误报风险高——与 open-hours-real-eval 同构的「静态表 vs 真实源」困境）；②官方签证 API（需凭证/资质，大概率关单）。结论大概率「静态表维护成本高 + 更新责任重，P3 或不排期」，但需一份正式评估记录。

**G4.【候选评估·backend/docs】task-mcp-export-eval：MCP 只读接口** — 证据：Everway 提供 MCP（Claude/ChatGPT/Cursor 里问「本次旅行总花费」，首行程免费）；我们 export JSON/ICS 是文件导出，无「其他 agent 可调用的标准接口」；既有 chat_trip_tools（get_my_trips/get_trip_overview，10-28 方案1）与 property-qa 已经具备只读查询内核。评估最小版：MCP server（薄壳包既有只读 API：get_trips / get_trip_overview / trip_export / property_qa，零新后端逻辑）+ README 自托管说明；风险：MCP 生态仍在演变、运行基础设施（自托管者可用）、用户群是 AI 重度用户。可行则最小版 + 文档；不可行记降级关单。

**G5.【内容沉淀·docs】content-google-maps-ask-maps：18 文《地图就是规划器？》** — 证据：Google Ask Maps（11-16 官宣，欧洲 30 国，行程生成/实时/导出 Docs）+ 豆包找店地图闭环（11-16）+ 携程 Trip.Planner/TripGenie（11-19 峰会，规划→预订转化 +400%）=「规划被嵌入地图/对话/OTA 主流程」的最强实证，是 14 文《巨头免费化》（10-15）、15 文《收购季》（11-07）、16 文《生成之后》（11-15）、17 文《收购季第二波》（11-18）之后的「平台挤压第三波」：规划不再以独立 App 形态存在，独立层剩「规划后链路深度（质检/修订/行中）+ 中立 + 免费」；接 15/16/17 文，代码引用逐条核验与仓库一致（四维质检/live today/六通道导入/导出/中立声明）。→ §2 候选池 P2。

**G6.（复核备注·不进队列）免费无注册 + 现成模板 = 2026 默认** — Nanajee 免注册 90+ 语言 + 30 现成 itinerary / Pangora 免费 5 次 / Mindtrip 免费全功能 / Escapada WhatsApp 免下载：11-18 G3 复核再确认；guest-trial 关闭结论（10-15）不矛盾，维持；「现成模板」我们已有城市模板 23 卡（getCityTemplates 在案）+ 灵感入口。

**G7.（复核备注·不进队列）IM 通道** — Escapada（今日 launch）/GuideGeek WhatsApp 系持续入场；IM 通道需第三方合规与凭证（11-07 已关单），维持不做。

## 四、对我们「小而锋利规划层」定位的含义

1. **生成器竞争的终局信号明确**：Google/字节/携程三大平台同期把「行程生成」做成默认能力（地图内/对话内/OTA 内）——**独立工具不再靠「能生成行程」立足**，这一点与 16 文《生成之后》完全吻合，且平台化速度比 11-15 预期更快。
2. **新缝隙 = 行前整理 + 提醒 + 对外输出**：Everway 证明「确认单归集、免费取消截止、签证检查、MCP」是未饱和需求，且都落在**生成之后、出发之前**的整理环节——与我们「规划后链路」主线同向（质检/修订/行中），只是再往前补一层「行前执行链」。
3. **我们的真实差距集中在前端接线而非后端内核**：escalation 评审队列（后端 10-28 已在 main，前端入口未接线）、多封确认单批量合并（email_import 内核可复用）、free_cancel_deadline（booking 台账字段扩展）——都是小步零凭证增量。
4. **巨头数据反证中立价值**：携程 TripPlanner 35% 来华行程 + TripGenie +400% 转化，OTA 的 AI 规划是漏斗第一层；我们「免费规划 + 中立跳转、不碰库存佣金」（11-08 中立显性化）仍是稀缺位，且 Google 导出 Docs / Everway MCP 表明「输出自由」正在成为行业对规划工具的默认期待——我们 JSON/ICS/打印已就位，MCP 是下一步。
